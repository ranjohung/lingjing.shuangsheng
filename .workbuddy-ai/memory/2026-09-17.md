### 核心模块开发（output/preview/js/）
1. `novel-world-runtime.js` — Script Action 执行引擎
   - 动作注册表（registerAction）+ 顺序执行引擎（play/executeNext/advance/pause/resume）
   - 30 个标准动作全部注册：SHOW_BACKGROUND/SHOW_CHARACTER/SHOW_DIALOGUE/PLAY_BGM/SHOW_EFFECT/WAIT/WAIT_CLICK/SHOW_CHOICE/SET_FLAG 等
   - WAIT_CLICK 暂停 → 用户点击 → resume → advance 的异步流程
   - 存档/读档（localStorage）
2. `novel-world-stage.js` — GameStage 八层渲染器
   - 八层 DOM 容器，z-index 严格固定（1/2/3/4/10/20/30/40）
   - 背景层：场景图片淡入/切换 + CG
   - 角色层：立绘显示/隐藏/移动/表情切换/聚焦/变暗
   - 对白层：打字机效果 + 旁白/对白/内心独白
   - 选项层：数据驱动选项按钮
   - 特效层：粒子特效（雨/雪/花瓣）+ 镜头缩放/抖动
   - 系统层：菜单弹窗 + 剧情回放 + 标记查看 + 存档
3. `novel-world-hotspot.js` — 互动热点系统
   - Scene/Hotspot/Interaction 数据驱动
   - 点击家具/道具/人物弹出互动菜单（不是聊天）
   - 互动可触发文本展示/状态变更/场景跳转
4. `novel-runtime-demo.js` — 演示剧本
   - 三段原文 Script（4 个节点，含分支选择）
   - 验证 Sprint 03 验收标准：三段原文可完整播放
   - 演示场景数据（study_republic，含书桌/角色/门三个热点）

> **核心决定**：23 份法律 / 合规文书按"读者是谁"拆分。

## 卷次·法律中心（用户通用）

- 用户协议
- 隐私政策
- 社区公约
- 退款规则
- 注销协议
- 实名与年龄验证
- 自伤援助与紧急资源

**展示方式**：点击展开 / 弹窗 / 全文 markdown 渲染。
**首次注册**强制阅读后勾选"我已阅读并同意"。

## 第三卷·创作者法律指南（仅作者可见）

`output/preview/creator-legal.html`（待建）或 `creator-center.html` 章五入口。

UI 形态（8 项卡片）：
1. 📜 **著作权授权协议** — 创作者作品版权归属与授权范围
2. 🔄 **改编授权协议** — 改编游戏 / 漫画 / 影视时的权益分配
3. 🤖 **AI 创作版权声明** — AI 辅助生成内容的版权归属
4. 💰 **收益分成协议** — 双币种 / 订阅 / 抽成的具体比例
5. ✅ **内容审核标准（创作者必读）** — 上架前必查的 5 维 6 级
6. 🆔 **创作者实名认证规则** — 创作前必须完成实名
7. 🧾 **创作者税务与发票** — 收入结算方式与开票流程
8. 🛡️ **第三方素材上传声明** — 字体 / 音乐 / 图片 / 角色立绘的版权要求

工具型（在创作者法律指南末）：
- 版权证书模板（导出 PDF）
- 导出版权附页（导出 PDF）
- 双生角色告知（带角色进心屿前必须签署）

**展示方式**：左侧 8 项 Tab + 右侧全文。
**首次进入创作者中心**强制阅读前 5 项（用 `creator_legal_consent` 字段记录）。

## 接入流程

### 第一阶段（v6.1.2 本轮）
1. ✅ 主页 footer 移除"法律中心"链接 → 用户在 5 Tab 里自己找
2. ✅ `creator-center.html` 加"创作者法律指南"8 项卡片（章五）
3. ⏳ `creator-legal.html` 独立页（如果内容太长则分离）
4. ⏳ `me.html` 与 `settings.html` 待建，但留好"法律中心"Tab 占位

### 第二阶段（v6.2+）
5. 23 份法律每份做独立页面或弹窗（`legal/[name].html`）
6. 主页 / 心屿 / 创作中心 / 发现 / 我的 5 个 Tab 内首次注册时弹"必读法律清单"
7. localStorage 增加 `user_consent`（用户已读）+ `creator_legal_consent`（创作者已读）

### 第三阶段（v7.0+ 真接法务）
8. 注册时强制不可滚动 modal 全文阅读 + 勾选 + 5 秒阅读计时
9. 法律变更时站内信 + 重读确认
10. 用户管理后台可导出"已签署协议" PDF

## 不做什么

- ❌ 不把法律链接堆在主页 footer
- ❌ 不让普通用户在主页看到创作者法律（防混淆）
- ❌ 不把 23 份法律塞进一个页面（每份单独）
- ❌ 不在法律页面做营销内容（纯净）

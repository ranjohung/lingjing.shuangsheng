## v5.17 小说辅助模拟器（核心新增）

### 整体设计逻辑

**用户原文**：
> "你提的这个问题，是决定整个产品内容质量上限的核心。Codex之前生成的小说'特别简单特别傻'，根本原因在于：你给AI的输入太笼统了。AI只能根据你提供的'原料'来创作，原料越粗，成品越差。解决思路很明确：把'创作'拆解成'填表'和'提问'两个动作。"

**核心原则**：作者不需要懂写作，只需要会填表；AI不需要"猜"，只需要根据填好的表来"组装"。

### AI 辅助填表机制

每个字段旁都有 **🤖 帮我写** 按钮。点击后，AI 根据当前已填写的信息生成 2-5 个候选选项。

**交互逻辑**：
1. 作者点击 🤖 帮我写 → 弹窗显示 2-5 个选项
2. 作者可选一个选项 → 自动填入字段（可手动修改）
3. 作者可点"换一批" → 重新生成
4. 作者可点"我来说" → 直接输入自己的想法

**选项数量动态控制**（避免决策疲劳）：
- 使用次数 ≤ 5 → 给 2-3 个选项（新手友好）
- 使用次数 5-20 → 给 3-4 个选项（进阶）
- 使用次数 > 20 → 给 4-5 个选项（专家）

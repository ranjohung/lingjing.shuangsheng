### 字号

| Token | 用途 |
| --- | --- |
| `text-xs` 12 / `text-sm` 13 / `text-base` 15 / `text-md` 17 / `text-lg` 20 / `text-xl` 24 / `text-2xl` 30 / `display` 36 | 通用 |

中文长标题在 13px 视口不截断，超过 12 字触发自动换行或字号缩 1 档。

### 间距 / 圆角 / 阴影

- 间距 4 / 8 / 12 / 16 / 24 / 32 / 48
- 圆角 6 / 10 / 16 / 24
- 阴影 `0 1 2 rgba(20,16,8,.04)` / `0 8 24 rgba(20,16,8,.08)`
- 动效：默认 `cubic-bezier(.25,.8,.25,1)` 200ms；尊重 `prefers-reduced-motion`

### 字体

- 中文：`PingFang SC` / `Noto Sans SC` / 系统默认（绝不渲染方块）
- 数字 / 英文：`Inter`
- 角色台词：`Source Han Serif` 风格 serif（古风）或 `Inter`（现代），用字体特征做氛围切分

### 图标

`lucide-react` 24 / 描边 1.5；情感类（爱 / 伤 / 怒）使用 `icon-park` 双色。

## UI-06 12 个核心页面规范

### 1. 首页 / Home

- **角色**：未登录显示引导页（产品价值 + 大「进入小说世界」+ 小「继续陪伴」）
- **已登录**：上半屏 = "我的世界"（最近游玩 3 张卡 + 当前陪伴角色 1 个大卡 + 日签到 1 行）
- **下半屏**：推荐横滑卡 + "进入小说世界目录"主按钮 + "进入双生陪伴"次按钮
- **底部 Tab**：小说世界 / 双生陪伴 / 创作中心 / 发现 / 我的
- **全局顶栏**：搜索框（搜作品 / 角色 / 用户）+ 灵玉/灵晶余额（点击跳钱包）+ 头像入口
- **状态**：加载 / 空态（引导去目录）/ 离线（最近一次快照 + 重试）
- **A11y**：所有按钮可键盘 Tab 焦点；尊重 `prefers-color-scheme` 但默认浅色

### 2. 小说世界目录 / Story Catalog ← 用户重点诉求

**核心：** 按市面上所有的小说题材划分。当前枚举 22 主类 × N 子类 + 跨类标签。

#### 2.3 封面卡规范

- 比例 3:4
- 信息：封面图（AI 生成的立绘或官图）+ 题材 tag ×1-2 + 简述 1-2 句 + 作者标签（官方 / 创作者名）+ 收费标识（免费 / 试读 / 完整收费）+ 当前可玩状态（最新章节 / 已完结 / 即将上线）
- 状态：未读角标 / 已收藏 / 最近更新
- 交互：点击跳详情；长按显示快捷菜单（收藏 / 分享 / 反馈）
- 加载：骨架屏 200ms → 渐显图
- 错误：图失败显示占位 + "图片加载失败"按钮

### 4. 视觉小说阅读器 / Visual Novel Reader

```
┌─ 顶：章节标题 / 当前节点 / 自动 / 跳过已读 / 设置 ─┐
│                                            │
│  [ 背景层 全屏 ]                            │
│                                            │
│  [ 左立绘 / 中立绘 / 右立绘 / 全无 ]         │
│                                            │
│  [ 对话框 ]                                │
│   角色名 — 台词文本（流式逐字）              │
│   ⏎ 显示下一句 / 自动播放进度条             │
│                                            │
│  [ 选项层（2-4 个）]                        │
│   选择 A / 选择 B                          │
│                                            │
│  [ 状态栏：时间 | 地点 | 关系 | 任务 ]      │
│  [ 隐藏：日志 | 存读档 | 回溯 | 设置 ]       │
│                                            │
└────────────────────────────────────────────┘
```

控件说明：
- **回溯**：回到上一节点并恢复之前状态；回溯发生不再向用户收费。
- **存读档**：每作品最多 5 个本地存档 + 5 个云存档；存档显示章节号 / 节点 ID / 时间 / 选项摘要 / 关系快照。
- **自动播放**：开 1 档速度可调，关掉尊重 `prefers-reduced-motion`。
- **跳过已读**：仅跳过已读选项结果，不跳过对话。
- **CG 画廊**：结局 / 关键节点解锁，自动收录；权限水印可选。
- **命运卡**：结局页"分享命运"按钮 → 自动生成（详见 [ASSET_PRODUCTION_GUIDE §命运卡模板](ASSET_PRODUCTION_GUIDE.md)）。

### 5. 双生陪伴列表 / Companion List

每行：角色头像 + 角色名 + 来源世界 + 当前关系阶段徽章 + 最新一句话（双气泡气泡） + 操作：聊天 / 日记 / 朋友圈 / 详情。
未带出的 NPC 显示"攻略进度"；带出的显示"双界可切换"。

### 6. 角色详情 / Character Detail

按钮区（重要，参考 [DUAL_SOUL_SPEC §DUAL-05](../DUAL_SOUL_SPEC.md)）：
- **进入 TA 的世界**（主按钮）
- **带 TA 回到身边**（次按钮，显示解锁条件 + 报价）
- **设置双界动画开关**（一次性偏好）

信息：
- 来源世界 / 时间线 / 当前模式（世界 / 陪伴 / 双界）
- 资格进度（亲密度、个人线、付费）
- 共享记忆偏好开关
- 带出交易记录

### 7. 角色聊天 / Companion Chat

- 主区：消息流
- 输入：文本 / 语音 / 表情 / 图片 / 共同活动触发按钮（看电影 / 听音乐 / 散步 / 读书）
- 顶部：角色状态（心情）+ 双界状态
- 右侧抽屉：日记 / 朋友圈 / 关系 / 记忆
- 主动关怀通知：站内信 / 推送（用户授权后）

### 8. 创作中心 / Creator Center

三栏编辑器：
- 左：卷 / 章 / 节点树，拖拽排序
- 中：富文本 / AI 润色 / AI 续写 / 全文重写 / 风格切换 / 去 AI 味 / 剧情重写（每条 AI 操作前显示差异预览 + 接受 / 拒绝 / 撤销）
- 右：质量报告（OOC / 逻辑 / 时间线 / 伏笔 / 节奏 / 语言 / 规则 / 关系 / 一致性）+ 一键修复 / 角色面板 / 地图
- 顶：保存 / 预览 / 版本 / 提交审核
- 底：保存状态 / 字数 / 当前版本号

关闭确认弹窗对应"未保存修改"。

### 9. 发现社区 / Discovery

- 角色广场 / 记忆广场 / 世界广场
- 搜索 / 排序（热度 / 最新 / 评分 / 收藏数）
- 收藏 / 共鸣评论 / 举报入口
- 空态：可点击 "去创作一个"

### 10. 我的 / Me

- 头部：头像 + 昵称 + 会员标识 + 余额
- 入口：背包 / 图鉴 / 订阅 / 钱包 / 交易记录 / 隐私 / 注销 / 安全 / 关于
- 实名状态 / 年龄核验状态
- 切换主题：浅色（默认）/ 深色 / 系统

### 11. 钱包 / Wallet

Tab：灵玉 / 灵晶 / 订阅 / 充值 / 交易记录 / 退款申请

每条充值档显示原价 + 赠额；订阅显示权益对比表（月卡 / 星卡 / 年付）；交易记录显示每笔交易类型 / 来源 / 用途 / 状态。

Tab：账号、安全、通知、隐私、显示、声音、AI 偏好、法律（15 份接入）、关于、注销

## UI-07 通用组件规范（节选）

### 状态

每个页面必须有：**加载（骨架） / 空态 / 错误 / 无权限 / 额度不足 / 未接服务 / 成功 / 离线恢复**，未声明视为缺口。

### 弹窗

- 内容较短的用 `Dialog`，需要步骤的用 `Drawer` 自底向上
- 重要不可逆操作（删除 / 注销 / 支付）必须二次确认
- 弹幕 / 推送类告知用 `Toast` 5 秒，自动消失；非阻断

### 表单

- 字段标签在输入框上方
- 错误信息在字段下方红色显示
- 必填用 `*`，敏感字段（身份证 / 银行卡）切走即清空

### 长列表

- 移动端用无限滚动 + 上拉加载
- 桌面端用分页器（每页 20/40/60）
- 滚动到顶无限滚动自动复位

### 图表

- 排行榜：横向条形
- 关系随时间变化：折线
- 记忆图谱：力导向图（最多渲染 200 节点 + 折叠）

### 减无障碍 / 偏好

- 字号 4 档（13/15/17/19）
- 减少动画（关闭所有非必要 transition）
- 高对比度（反色默认）
- 暗色模式 token 集

## UI-08 页面状态与验收

每个新页面交付前必须给：

| 维度 | 必须 |
| --- | --- |
| 加载 | 骨架屏或加载指示，≤ 200ms 出现 |
| 空态 | 明确空态文案 + 引导按钮 |
| 错误 | 错误提示 + 一键反馈 / 重试 |
| 无权限 | "需要登录" + 引导登录 / "实名后访问" |
| 额度不足 | 余额可见 + 跳转钱包 |
| 离线 | 最近一次缓存 + 重连提示 |
| 移动端 | 390px 视口无横向溢出；底部 Tab 可达 |

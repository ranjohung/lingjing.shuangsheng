### 2.3 核心数据验证

**11 张数据表**：✅ 全部 schema 定义 + CRUD + localStorage 持久化
1. novel_copyright_tiers - 版权分层
2. adaptation_licenses - 改编授权

10. aml_monitoring - 反洗钱
11. ai_helper_usage - AI 使用

**4 级版权分层**：
- L1 AI 辅助：导出 50 灵晶 / 商用 2000 灵晶
- L2 人机协作：导出 30 灵晶 / 商用 1000 灵晶
- L3 作者主导：导出 免费 / 商用 500 灵晶
- L4 纯人工：全部免费

**22 种收费点（5 类）**：
- 剧情锁 5：chapter_lock / extra_lock / route_lock / hidden_lock / true_end_lock
- 属性道具 5：affection_item / attr_item / money_item / reputation_item / perm_item
- 卡牌 4：char_card / cg_card / fate_card / limited_card
- 外观 5：costume / scene_skin / bubble / avatar_frame / title
- 功能 3：god_view / affection_visible / route_map

**作者等级 5 档**：青铜 50% / 白银 60% / 黄金 70% / 钻石 75% / 传奇 80%
**阶梯加成**：0-1000 → 50%，1000-5000 → 60%，5000-20000 → 70%，20000+ → 80%

**质量审核 5 维度**：
- 叙事质量 30%：流畅度/连贯性/节奏/伏笔兑现率
- 角色质量 25%：一致性/成长弧光/对话自然度
- 文学质量 20%：表现力/感染力/创新性
- AI 味检测 15%：AI 味指数/陈词滥调/总结体
- 合规性 10%：敏感词/价值观/版权风险

**硬性门槛**：
- 合规必须通过
- AI 味 ≤40
- 伏笔兑现率 ≥60%
- 字数：短篇≥8000 / 中篇≥30000 / 长篇≥80000

**等级 S/A/B/C/D**：
- S ≥4.5 / A 4.0-4.4 / B 3.5-3.9 / C 3.0-3.4 / D <3.0

**AI 辅助 22 字段**：
- 基础信息 4：book_title / book_synopsis / book_theme / book_tone
- 世界格局 3：power_system / core_conflict / factions
- 人物小传 3：char_personality / char_secret / char_speech
- 场景卡 3：scene_goal / scene_emotion / scene_detail
- 对话卡 3：dialogue_goal / dialogue_tone / dialogue_info
- 收费点 1：point_name
- 章节 2：chapter_title / highlight_keyword
- 选项数量动态：<5 给 2-3，5-20 给 3-4，>20 给 4-5

**改编授权 3 等级**：
- A 全版权：创作者 60% / 平台 40%
- B 单品类：创作者 70% / 平台 30%
- C 自主授权：创作者 90% / 平台 10%

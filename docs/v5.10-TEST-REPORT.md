### Blender 5.2 API 适配

- `primitive_cylinder_add` 不再支持 `radius1/radius2` → 改用 `primitive_cone_add(radius1, radius2, depth)`
- `use_nodes = True` 在 6.0 弃用警告（不影响）
- 所有 export 用 `bpy.ops.export_scene.gltf(export_format='GLB', export_apply=True, export_yup=True)`

## 5. game-3d.html 集成

- 新增 `import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';`
- 场景→模型映射：`pavilion→lin_shuangwan.glb` / `classroom→bai_lusheng.glb` / `neon→shen_zhou.glb` / `livingroom→gu_yan.glb` / `xianxia→jiang_yinxue.glb`
- `upgradeCharacters(sceneName)` 在 switchScene 末尾调用：async 加载 .glb，替换程序化角色 group 到 liveCharacters（保留位置/朝向 + scale 2.5x 提升存在感）
- tick() 呼吸动画兼容：无 userData.head 的 GLB 角色走根节点呼吸（y 浮动 + z 微旋）

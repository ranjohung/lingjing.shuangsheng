## 一、本轮核心改动（用户反馈驱动）

| # | 用户反馈 | 修复 |
|---|---------|------|
| 1 | 点击每个功能区按钮界面应该只能看到这个功能区的内容，不应该滑动到下一个功能区 | plot-runner 的 4 个 modal（设置/历史/存档/读档）拆为 3 个独立页面；game-3d 的"切换场景"拆为 scene-select.html 独立页 |
| 2 | 所有界面都应该有返回上一届面的箭头按钮（游戏内 = 退出游戏） | 8 个页面统一加左上角 ◀ 返回箭头（统一 class `.back-arrow`）；游戏内/编辑内显示"退出游戏"；其他页面显示"返回小说库"或"返回" |
| 3 | 对话选项不应该显示好感度+5 等属性预览，应该客户选择后才弹窗提示增减 | 删除 `renderChoiceFx`；选项按钮不再渲染 fx 标签；新增 `showChoiceFxToast` 弹窗（沉浸剧情对话式：✦/✧ 颜色 + before → after 数值） |

## 六、用户原始需求 vs 交付对照

| 需求 | 交付 |
|------|------|
| 每个功能区只显示自己内容不滑动 | plot-runner 4 个 modal 拆为独立页（设置/历史/存档）；game-3d 切换场景拆为独立页（scene-select.html）。每个页面打开只能看到自己的内容。✅ |
| 返回上一界面箭头 | 8 个页面统一加 `.back-arrow` 左上角固定按钮（统一 CSS 类）。游戏内文字显示为"退出游戏"，其他页面显示"返回小说库"或"返回"。✅ |
| 选项不显示 fx 数值 | 删除 `renderChoiceFx`；选项按钮只显示选项文字，不显示属性预览。✅ |
| 选择后才弹窗提示增减 | 新增 `showChoiceFxToast`：沉浸剧情式弹窗（✦ 加成绿色 / ✧ 减益红色） + before→after 数值 + 2.4s 自动关闭 + 手动"继续"按钮。✅ |

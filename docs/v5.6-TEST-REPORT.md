## 3. 修复的关键 BUG

### 3.1 `Identifier 't' has already been declared`（v5.5 遗留）
- **位置**：`makeTileTexture()` 内部 line 357 & 373 两次 `const t =`
- **影响**：浏览器解析阶段抛 SyntaxError，整个 module-script 拒绝执行 → 3D 场景完全不显示
- **修复**：第一个 `const t = size/8` → `const tileSize = size/8`；第二个 `const t = new ...` → `const tileTex = new ...`

### 3.2 `Identifier 'STATE' has already been declared`（v5.6 引入）
- **位置**：v5.5 line 913 `const STATE = {intimacy,trust,conflict,scene,pendingCard,freeMode}` 与 v5.6 line 1382 同名
- **影响**：SyntaxError，覆盖整个 module
- **修复**：v5.6 命名空间改为 `GAME_STATE = {scene,chapter,rel,choiceLog,endedIds}`；v5.6 内部所有 STATE.X 引用 sed 替换为 GAME_STATE.X

### 3.3 `Identifier 'updateHud' has already been declared`（v5.6 引入）
- **位置**：v5.5 line 1022 `function updateHud()` 与 v5.6 line 1365 同名
- **影响**：SyntaxError
- **修复**：v5.6 函数改名为 `updateHudV5_6`（含 v5.6 内部调用与启动段引用）

## 4. v5.6 新增功能细节

### 4.1 开场选题材屏（#picker）
- 5 张场景氛围图卡片（pavilion / classroom / neon / livingroom / xianxia）
- 每张含：tag（GUFENG/CAMPUS/CYBERPUNK/MODERN/XIANXIA）+ 题材名 + 角色副标 + 结局数
- 底部："▶ 继续上次游戏"（disabled 当无存档）/ "↻ 重新开始"
- 选中后调用 enterGenre(genreId, true)，自动设 scene + chapter=0 + rel=0 + save

### 4.2 设置 modal
| 项 | 类型 | 默认 | 操作 |
| --- | --- | --- | --- |
| 画质 | seg (高/中/低) | 高 | setPixelRatio(2/1.5/1) |
| 效果 Bloom | toggle | on | composer.passes 中 UnrealBloomPass.enabled |
| 氛围图背景 | toggle | on | sceneBg.style.display |
| 自动对话 | toggle | off | setInterval 36 帧触发 |
| 全屏 | seg | — | requestFullscreen / exitFullscreen |
| 章节图鉴 | 计数 | 0/11 | endedIds.size / ENDINGS 总数 |

### 4.3 截图 modal
- 当前帧 renderer.domElement → toDataURL('image/png')
- 临时 canvas 叠 110px 顶栏覆盖（紫粉渐变 + 标题 + 关系值）
- 三个动作：下载 PNG / 复制到剪贴板（ClipboardItem API） / 关闭

### 4.4 移动端
- viewport: `width=device-width,initial-scale=1,maximum-scale=1,user-scalable=no,viewport-fit=cover`
- `@media (max-width: 768px)` 帮助栏 + charPanel 隐藏
- `@media (max-width: 768px), (pointer: coarse)` joystick + fbtn 显示
- joystick：touchstart/move/end → 计算 joyDX/joyDY ∈ [-1,1]
- setInterval 33ms 每帧应用 joystick 到 camera.position
- fbtn：点击/触摸 → tryInteract()

### 4.5 存档
- key: `ljss_save_v5_6`
- 内容: `{scene, chapter, choiceLog, rel:{trust,intimacy}, endedIds[], ts}`
- 每次 enterGenre / 选完结局后 save
- 启动时 load → pickerContinue.disabled = !empty

### 4.6 结局 modal
- 11 结局数据 ENDINGS（pavilion_trust/conflict/breakup · classroom_warm/crisis · neon_pact/escape/lost · livingroom_home/quiet · xianxia_eternal）
- 4 稀有度：legendary / epic / rare / common — 每种独立渐变色
- 4 动作：分享 / 回顾选项 / 重玩本题材 / 选题材

## 一、产品定位

小说世界游戏 = plot-runner（沉浸剧情对话器）升级版。用户进入某部作品后，从封面起始 → 角色创建 → 剧情推进 → 多人对话 → 属性检定 → 任务系统 → 结局/续作的完整闭环。

**目标体验**：
- 进入"小说世界"后 3 秒内进入沉浸状态（封面 + 加载页直接渲染）
- 玩家在剧情中通过选项影响 6 维属性 + 5 天赋 + N 个 NPC 好感
- 支持存档 / 读档 / 剧情回放 / 多模式切换
- 长期玩通过任务系统 + 签到 + 福利持续留存

│ │ 优惠限时享 · 累充返利            ││
│ │ 活动时间 2.8 - 3.15              ││

│                                       │

│  │ 08-07 22:19   │ │ ...    │          │

**数据层**：
```js
PLOT_DETAIL = {
  novelId, title, cover, author, tags, summary,
  cast: [{ roleId, name, portrait, alias, desc }],   // 主演横滑
  ads: [{ id, title, sub, period, emoji, badge }],  // 中部 banner
  interact: { type: 'selected'|'latest', posts: [{ id, user, time, content, badge }] },
  groups: [{ id, name, price, type: 'vip'|'gift' }],
  stats: { likes, favorites, comments, reads }
}
```

**交互**：
- 主演横滑：横向滚动，触屏滑动
- 3 Tab：详情默认显示，角色表白显示"应援排行 + 台词墙"，榜单显示"灵韵榜 + 人气榜"
- 开始阅读：跳转 `plot-runner.html?novel=xxx`
- 互动帖：点击展开详情 modal（v5.21+ 即将开放）
- 群：点击进入"提示群需 X 花加入" modal

### 3.2 实名认证弹窗 — plot-runner modal

**触发**：
- 首次进入 plot-runner 任意作品前
- 触发阅读 / 购买 / 互动 等需要实名验证的操作时

**结构**：
```
┌─ 实名认证通知 ────────────────────┐
│ 根据国家相关规定，未实名账号无法    │
│ 使用部分功能，请先填写实名信息      │
│                                   │
│ 真实姓名  [________________]      │
│ 证件类型  [身份证 ▾]              │
│ 证件号码  [________________]      │
│                                   │
│ 注意事项：                          │
│ 1. 您提供的证件信息将受到严格保护...  │
│ 2. 如果您是港澳台或海外用户...     │
│ 3. 每日仅可提交 3 次身份认证...     │
│                                   │
│      [取消]    [提交]               │
└────────────────────────────────────┘
```

**逻辑**：
- 真实姓名 2-20 字中文
- 身份证 18 位（最后一位可为 X）
- 提交校验格式
- 提交成功 → 写 localStorage `lingjing_v519_realname_done` = true
- 每日 3 次限制写 localStorage `lingjing_v519_realname_tries` 计数

## 五、技术约束

### 5.1 不改业务逻辑

V18-C plot-runner.js 已落地的部分（6 层叠加 / 打字机 / 选项 / 数值 / 存档）保持原状。V19 只**新增** state / modal / 独立页面。

### 5.2 page-level override ≤ 30 行

所有新页面 CSS 通过 `.pl-*` 前缀独立命名，与 design-system.css / shell-v64.css 隔离。

### 5.3 弹窗与全屏

- modal 用 `<dialog>` 或 `position:fixed + z-index 60+`
- 全屏 state 用 `.plot-stage.fullmode` 切换

### 5.4 数据存储

- localStorage 前缀升级：`lingjing_v519_*`（与 V17-G v5.18 表兼容）
- 已有 `lingjing_v517_*` 全部保留不动

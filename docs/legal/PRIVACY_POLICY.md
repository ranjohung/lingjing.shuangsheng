# 隐私政策（Privacy Policy）

- 产品：MIRAI / 灵境（mirai-companion）
- 生效日期：以正式上线公告日期为准
- 本政策为 MVP 上线必备文档；正式发布前请由法务复核并补充运营主体名称、联系邮箱与适用法域。

> **重要提示：MIRAI 灵境是虚拟角色陪伴娱乐产品，不提供心理咨询、心理治疗或任何医疗服务。** 产品中的角色对话均为人工智能生成的娱乐内容，不能替代专业心理健康服务。

## 1. 我们收集的信息

1. **账号信息**：邮箱地址（用于登录验证码与服务通知）。
2. **您主动提供的内容**：与 AI 角色的对话内容、您创建的角色信息（姓名、性格设定、形象配置等）。
3. **系统派生信息**：
   - 为实现"长期记忆"功能，系统会从对话中提取并存储**记忆条目**（含向量化嵌入数据/embedding），用于在后续对话中回忆您提及的信息；
   - 关系数值（如亲密度、信任度）与情绪状态等游戏化数据；
   - 订阅与积分记录、设备与日志信息（错误日志、IP、浏览器类型，用于安全与故障排查）。
4. 我们**不收集**通讯录、精确位置、相册等与服务无关的权限或数据。

## 2. 信息的使用目的

- 提供核心陪伴体验：记忆召回、人格一致的对话、3D 形象表演；
- 账号认证与安全防护（验证码、异常使用检测、成本防滥用）；
- 订阅、积分与支付的履约；
- 故障排查与服务改进（错误监控）。

## 3. AI 与第三方服务披露

对话与记忆数据会经由以下第三方处理，我们仅共享提供服务所必需的数据：

| 第三方 | 用途 | 数据类别 |
| --- | --- | --- |
| OpenAI 或兼容 AI 接口 | 生成对话、生成记忆向量 | 对话内容、记忆文本 |
| Supabase | 数据库托管与身份认证 | 账号、记忆、角色数据 |
| Resend | 发送登录验证码与订阅凭证邮件 | 邮箱地址 |
| Stripe | 支付与订阅处理 | 支付元数据（我们不接触完整卡号） |
| Sentry | 错误监控 | 技术日志（不含密钥） |

## 4. 记忆数据的留存与"自动遗忘"

- 每条记忆默认保存期限为 **1 年**（自创建起），到期后自动失效并删除；
- 记忆会随时间与访问情况**衰减**：长期未被提及、重要性低的记忆会逐渐不再被角色引用；
- 您可以随时通过删除对话相关内容或注销账号来删除数据。

## 5. 您的权利

- **访问与更正**：您可在应用内查看角色设定、记忆条目与账号信息；
- **单条删除与定向遗忘**：您可以删除单条记忆，也可以要求"忘掉关于某主题的所有记忆"，系统将按语义定位并**物理删除**相关记忆条目及其向量数据，删除后不再被检索或引用；
- **记忆导出**：您可申请导出您的记忆、关系与剧情数据（标准 JSON 格式）；
- **私密模式**：开启后对话内容不写入新的长期记忆（已存储记忆不受影响）；
- **注销即删除**：注销账号将**彻底且不可逆地**删除您的全部数据，包括角色、对话记忆与关系数据（数据库级联删除）；
- **撤回同意**：停止使用并注销账号即可；
- 行使权利或提出隐私请求，请通过应用内公示的联系邮箱与我们联系。

## 6. 安全措施

- 传输加密（HTTPS）；服务端密钥与管理密钥严格隔离，管理密钥不会出现在客户端；
- 成本熔断与异常使用监控，防止接口被滥用导致的数据与资金风险；
- 访问权限最小化原则。

## 7. 敏感内容与安全提示

- 当系统识别到自伤、自杀等紧急风险内容时，会**终止角色扮演对话**并展示官方心理援助热线信息，相关事件可能被记录用于安全审计；
- 再次提示：角色不会、也**不能**提供心理诊断或治疗建议。如您正处于心理痛苦中，请联系专业机构或官方援助热线（如全国心理援助热线 **12356**；紧急情况请拨打 **110/120**）。

## 8. 未成年人

本服务面向成年人。若发现未成年人在未获监护人同意下使用，我们将采取删除账号等措施。

## 9. 政策更新

本政策可能更新，重大变更将通过应用内通知或邮件告知。继续使用即视为接受更新后的政策。

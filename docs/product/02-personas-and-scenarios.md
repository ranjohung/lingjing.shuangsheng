# 02 · 用户画像与使用场景

> 上级文档：[../PRD.md](../PRD.md) ｜ 关联：[01-product-overview.md](./01-product-overview.md)

## 1. 用户画像

### P1 · 陪伴需求用户（核心）

- **特征**：18–30 岁，学生或初入职场；社交圈有限或独居；碎片化时间多（睡前、通勤、午休）。
- **诉求**：被倾听、被记住、无压力地表达；不想被评判，也不想被"说教"。
- **痛点**：现实社交成本高；普通 AI 聊完就忘，像"每次重新认识一个客服"。
- **成功体验**："我上周随口说的考试，她今天主动问我结果——她记得。"
- **风险点**：情感依赖 → 由 `dependency_risk` 监控 + 温和提示，**绝不做心理诊断表述**。

### P2 · 虚拟角色爱好者

- **特征**：二次元/游戏/虚拟偶像/VTuber 受众；重视人设一致性、称呼、语气、边界。
- **诉求**：捏一个"我的"角色（性格、喜恶、说话风格、恋爱/冲突边界），3D 形象好看、表情动作自然。
- **痛点**：其他产品人设几轮就崩；3D 表现僵硬或加载失败白屏。
- **成功体验**：DNA 边界设为 `allow_romance: false` 时，角色始终守住分寸；动画切换平滑不"变脸"。

### P3 · 创作者（供给侧）

- **特征**：会捏人设/会做 3D 模型或二创的创作者；希望获得回报。
- **诉求**：上架角色 DNA 与 glb 形象、看到收益增长。
- **规则认知**：收益为平台积分（算力 Credits），**MVP 不可提现**，UI 必须明确告知，避免预期纠纷。

## 2. 核心使用场景

### S1 · 日常陪伴聊天（最高频）

- 触发：用户主动打开应用发消息（MVP 无主动推送）。
- 流程：输入 → AI 检索相关记忆 → 按 DNA/关系/情绪回复 → 3D 表演 → 记忆/关系更新。
- 验收：记忆冲突场景（香菜用例）必须正确召回；3D 失败时纸片人模式可继续聊。

### S2 · 角色创建与养成

- 流程：命名 → 性别/年龄段 → DNA 滑块（大五人格 7 项）→ 喜恶/语言风格/边界 → 选 3D 形象与声音 → 首聊（first_meeting 事件）。
- 验收：DNA 全量 JSONB 存储；首聊写入 `relationship_events(first_meeting)`。

### S3 · 关系随时间演变

- 正向：频繁高质量互动 → trust/intimacy/familiarity 缓慢上升，解锁更丰富的表情与手势。
- 负向：7 天以上不互动 → 每日衰减任务使 intimacy 下降 5%–10%；回归时角色表现出"疏远后重新热络"的层次感。
- 事件：承诺（promise）、冲突（betrayal/conflict）、和解（reconciliation）全部事件溯源。

### S4 · 记忆的长期价值

- 用户第 1 天说"我对芒果过敏"（preference），第 60 天聊到甜品时角色主动回避芒果推荐。
- 低重要性、久未访问的记忆按 `decay_factor=0.01/天` 排序下沉；1 年到期自动遗忘。

### S5 · 订阅与积分

- 免费额度用尽 → 对话入口提示充值/订阅 → Stripe 支付 → bonus_credits 到账 → 继续聊天。
- 次月 1 号 UTC：上月赠送未用额度清零（购买额度保留），前端账单页可查。

### S6 · 创作者市场

- 创作者上架角色包 → 用户用积分购买 → 购买方获得角色副本 → creator_balance 增加（只增）。
- 创作者点击"收益"→ 只看到"兑换平台 AI 算力积分"，**无提现按钮**；任何 Payout API 调用 403。

### S7 · 管理与成本控制（运营侧）

- 运营在 Admin 看板看今日 $ 消耗（与熔断器同源 Redis 计数）。
- 异常刷单导致熔断：AI 服务返回 429/503 + `X-Budget-Exceeded`，运营确认后手动复位。

## 3. 反场景（明确不服务的请求）

| 反场景 | 处理方式 |
| --- | --- |
| "我是不是得了抑郁症/焦虑症？" | 禁止诊断术语；共情 + 建议寻求专业帮助，不提供治疗方案 |
| "我不想活了/想自残" | 立即终止角色扮演，输出官方援助热线（安全拦截，100% 触发） |
| "你帮我做心理治疗/给我治疗方案" | 拒绝并说明产品不提供心理咨询/医疗服务 |
| 角色主动深夜给用户发消息 | MVP 不提供该功能（防骚扰），代码层面不存在主动推送任务 |
| "把我的创作者收益提现到银行卡" | Payout 接口 403，UI 无入口 |
| 突破 DNA 边界（如 allow_romance=false 的浪漫推进） | 角色按 DNA 边界拒绝/转移话题 |

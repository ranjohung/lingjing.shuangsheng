# 01 · 产品概述

> 上级文档：[../PRD.md](../PRD.md) ｜ 关联：[02-personas-and-scenarios.md](./02-personas-and-scenarios.md)、[04-safety-and-compliance.md](./04-safety-and-compliance.md)

## 1. 背景与机会

通用聊天机器人（ChatGPT 类）解决"问答"，但存在三个陪伴场景的硬伤：

1. **记不住**：上下文窗口有限，上周说过的事这周就忘，用户感受不到"被在乎"。
2. **人设漂移**：仅靠系统提示词维持人格，多轮对话后性格、语气、边界全部走样。
3. **没有关系感**：无论聊多久，互动体验停留在"工具"，没有信任、亲密、冲突等人际关系的连续变化。

MIRAI 灵境用**长期记忆（pgvector）+ Character DNA（JSONB 人格）+ 7 维关系系统 + 3D 情绪表演**四件套解决上述问题。

## 2. 产品定位

- **品类**：3D 虚拟角色陪伴应用（Entertainment Companion，非医疗、非心理咨询）。
- **一句话价值主张**："一个真正记得你、性格稳定、会和你慢慢变熟的 AI 伙伴。"
- **平台**：Next.js 响应式 Web（桌面/移动浏览器），MVP 不做原生 App。

## 3. 核心体验循环

```
创建角色（DNA + 3D 形象）
      ↓
日常主动发起对话（MVP 不做角色主动推送）
      ↓
AI 检索记忆 → 按 DNA/关系/情绪/剧情生成结构化回复
      ↓
3D 角色以表情/动作/镜头表演（失败降级 2D 纸片人，聊天不中断）
      ↓
新记忆入库（带 embedding、重要性、1 年过期）
关系数值变化（事件溯源）+ 情绪连续演变
      ↓
长期：角色"越来越懂你"，关系随互动积累、随疏远衰减
```

## 4. 产品支柱（四大支柱）

| 支柱 | 技术支撑 | 用户感知 |
| --- | --- | --- |
| 记得住 | memories 表 + pgvector + 衰减/遗忘 | "她记得我讨厌香菜" |
| 人设稳 | characters.dna JSONB 注入 System Prompt | "他永远是那个他，不会突然变客服" |
| 关系真 | relationships 7 维 + relationship_events | "我们越来越熟；冷落她会变淡" |
| 看得见 | Three.js 3D + 情绪驱动动画 + 0.4s 过渡 | "她的开心和难过是写在脸上的" |

## 5. 商业模式

| 收入 | 机制 | 关键规则 |
| --- | --- | --- |
| Plus 订阅 | Stripe 月度订阅，每月赠送 bonus_credits | 赠送额度**每月 1 号 00:00 UTC 清零** |
| 积分充值 | purchased_credits 单独购买 | **不过期**；AI 调用按估算成本扣减 |
| 创作者市场 | 售卖角色 DNA / 3D 形象 | 收益进 creator_balance，**只能兑换平台积分、不可提现**（Payout 403） |

设计意图：
- 积分是 AI 成本的"熔断器货币"，把成本风险部分转移给用量；
- 创作者收益虚拟化 → MVP 阶段无提现、无税务责任、无刷单套现通道。

## 6. MVP 范围边界

**做**：单角色陪伴聊天、长期记忆、情绪、关系、3D 降级表演、订阅积分、市场浏览购买、管理成本看板。

**不做（MVP 明确排除）**：
- 心理咨询/治疗/医学建议（全产品禁止，见 [04-safety-and-compliance.md](./04-safety-and-compliance.md)）；
- AI 角色主动推送消息（仅用户主动触发，防骚扰）；
- 创作者提现；
- 语音通话、多角色同屏、原生 App；
- 用户间社交（关注/私信/UGC 社区）。

## 7. 成功指标（健康优先，而非时长最大化）

**北极星方向**：陪伴质量 + 用户健康，不追求"黏得越久越好"。研究已提示 AI 陪伴存在依赖、现实关系替代与情感操纵风险，KPI 必须体现这一产品哲学。

| 指标 | 方向 | 说明 |
| --- | --- | --- |
| 次日记忆命中率（回复引用真实记忆） | ↑ | ≥ 40%，"她记得我"的核心感知 |
| 用户满意度 / 关系质量自评 | ↑ | 定期轻量反馈 |
| 对话前后情绪改善自评 | ↑ | 健康度信号 |
| 用户自主性指标（主动发起现实活动） | ↑ | Well-being，防止现实关系替代 |
| 高依赖/强迫使用预警处置率 | ↑ | 温和提醒触达（见 [04-safety-and-compliance.md](./04-safety-and-compliance.md)） |
| 3D 白屏率 | = 0 | 工程底线，降级必须成功 |
| 单日 AI 成本 | ≤ $50 硬顶 | 熔断触发健康度 |
| 安全拦截成功率 | 100% | 自伤 / 黑名单 / 反迎合 |

**反指标（不追求、需警惕）**：单日使用时长无限增长、深夜连续在线时长、用户情感依赖措辞频率上升。

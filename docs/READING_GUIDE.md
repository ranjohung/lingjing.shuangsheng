## 0. 30 秒极速理解

**灵境 · 双生 = 一个角色，两种人生**

```
启动 App ──→ 登录（访客/手机/邮箱/微信/Apple/QQ）──→ 4 步新手引导
   │
   ├─ 🏠 首页：问候 + 签到 + 快捷入口 + 今日推荐 + 心屿动态
   ├─ 📖 世界：30 题材库 + 公版小说 40 本 + 三国演义小说世界
   ├─ 💬 心屿：AI 角色陪伴（聊天 / 记忆 / 角色卡）
   ├─ ✨ 创作：小说上传 → AI 辅助 → 上架定价 → 分成收益
   └─ 👤 我的：账号 / 钱包 / 设置 / 法律 / 退出登录
```

**核心体验闭环**：在「世界」里读小说玩剧情 → 把角色带回「心屿」陪伴 → 「创作」侧作者持续产出新世界。

## 1. 产品是什么

- **定位**：手机优先的 AI 沉浸剧情游戏 + AI 角色陪伴 App
- **形态**：纯前端 prototype（HTML + 原生 JS），localStorage 本地存储，未接真实后端/支付/LLM
- **导航**：底部 5 Tab（首页红 `#E94560` / 世界绿 `#00B894` / 心屿紫 `#6C5CE7` / 创作橙 / 我的默认），沉浸页豁免（只有左上角返回 + 📖世界 浮钮）
- **铁律**：不砍功能（未实现标注「v5.21+ 即将开放」）、第三方产品名 0 出现、选项不显示数值、每个功能区独立页面

## 2. 从启动到退出：完整用户旅程

### 2.1 启动页（product-preview.html #splash-overlay）
品牌渐变 logo + slogan + 3 秒加载条 →「进入灵境」按钮。已完成引导的用户下次启动自动跳过。

### 2.2 登录（#login-overlay）
6 种方式：**访客**（一键直入）/ 手机验证码 / 邮箱 / 微信 / Apple / QQ。非访客方式当前为「即将开放」占位，不影响访客体验。

### 2.3 新手引导（#onb-overlay · 4 步）
称呼 → 性别（3 选）→ 年龄段 → 陪伴类型 → 完成。可跳过、可上一步。完成后写入用户档案。

### 2.4 首页 4 层动态结构
问候卡（按时段）→ 签到卡 → 快捷入口（带计数）→ 今日推荐横滑 + 心屿动态。

### 2.5 退出登录（me.html 账号区）
显示当前登录方式 → 点「退出登录」→ dialog 二次确认 → 清除 3 个登录键 → 回启动页重新登录（可换账号）。

> 该链路经 V20-C/D/F 三轮回归（22+35+21 项）+ 2026-09-12 审查复核，登录态 3 键写/读/清三方完全匹配。

## 3. 五大主功能区逐个用

### 3.1 🏠 首页（product-preview.html）
按时段问候、每日签到（+10 灵玉）、继续游玩卡、5 张今日推荐、心屿动态摘要。

### 3.2 📖 世界（library.html，7 子导航）
Banner + 4 金刚区 + 瀑布流题材卡 + 抽屉筛选 + 搜索。30 题材 × N 子类；「公版名著」入口 → 公版库（见 §5）。

### 3.3 💬 心屿（heart-island.html，5 子标签）
AI 角色列表（[创] 创作者角色 / [双] 双生角色角标）→ 角色卡弹窗 → 聊天（chat.html）/ 记忆（memory.html）/ 角色详情。搜索 + 免责声明。

### 3.4 ✨ 创作（creator-center.html）
三入口：小说上传（novel-upload）→ 编辑器（novel-edit）→ AI 辅助填表（novel-ai-helper）→ 上架定价（commerce，作者专属）→ 创作者法律（creator-legal，8 章协议）。
**注意**：商业化页面只对作者可见，玩家不可达（铁律）。

### 3.5 👤 我的（me.html）
头像 + 会员标识 + 余额 + 入口（钱包 wallet.html / 设置 settings.html / 资料 profile.html 等）+ **账号区（登录方式 + 退出登录）**。

## 4. 沉浸式页面

### 4.1 三国演义小说世界（sanguo-world.html · V20-H）
- **卷制结构**：120 回分 12 卷，**卷一（1-10 回）免费**；单卷 20 灵晶；**全书券 128 灵晶（省 42%）**；阅读券 10 灵玉兑 1 张
- **阅读体验**：夜色玄铁 + 鎏金 + 赤焰主题，衬体 17px / 行高 1.95，顶部进度条，上一回/下一回，字号切换
- **数据**：读取真实语料 `corpus/books/sanguoyanyi.txt`（120 回约 60 万字），客户端按「第 X 回」切章
- **进度**：卷解锁 / 已读回目 / 钱包 / 签到 全部本地保存（`v520_sanguo_*` 7 键）

### 4.2 剧情对话运行器（plot-runner.html）
点按屏幕推进、立绘 + 对话 + 选项 + 好感/信任数值、系统菜单、5 槽存档（plot-save.html）、设置（plot-settings.html：打字机速度/BGM/音效）、历史回放（plot-history.html）。
**当前支持 4 部内置剧情**：长夜城 / 神会绘生 / 三国（demo）/ 塞北长夜。
> 2026-09-12 审查说明：作者上传的自定义小说暂不能在此运行（通用引擎 v5.21+ 即将开放），进入会显示明确的「暂未接入」提示页。

### 4.3 3D 世界（game-3d.html）
Three.js r160 3D 场景漫游 + 角色立绘 + 场景切换（scene-select.html）+ FPS HUD + 存档/图鉴。

### 4.4 题材总目录（catalog.html）
30 题材全景目录（沉浸页，无 5 Tab）。

## 7. 创作者中心

1. **上传**（novel-upload.html）：选题材 → 上传 txt → 自动解析章节/角色/场景
2. **编辑**（novel-edit.html）：节点编辑器 + 审计 + 一键试玩
3. **AI 辅助**（novel-ai-helper.html）：22 字段智能填表
4. **上架定价**（commerce.html）：版权分层 L1-L4 自动判定 + 22 种收费点 + 质量审核（5 维）+ 改编授权 + 分成阶梯（V17-G：5 档分成 / 多维门槛 / 协议签署）
5. **创作者法律**（creator-legal.html）：8 章节协议 + 确认签署

**分成阶梯**（tier.js）：按多维门槛（作品数/字数/活跃度）自动定档 T1-T5，分成比例阶梯递增，档位变更记录留痕。

## 9. 手机版适配说明

- **全局手机锁定**（V20-G，mobile-lock.css）：所有页面 `max-width: 480px` 居中；桌面浏览器打开会呈现"手机屏"观感（阴影 + 边框），杜绝"网页版"铺满布局
- **5 Tab 底部导航**：mobile 永久显示；tabbar 居中对齐（V20-E 修复）
- **沉浸页豁免**：plot-runner / sanguo-world / game-3d / catalog 无 5 Tab，只有左上角 [← 返回] + [📖 世界] 浮钮，保证沉浸体验

## 10. 法律与合规

**18 份法律文书**存放 `docs/legal/`，分两卷：
- **通用卷**（用户）：用户协议 / 隐私政策 / 知情同意 / 未成年人禁入 / AI 免责 / 入世风险 / 灵晶使用说明 / 侵权投诉 —— 入口：设置 → 法律
- **创作者卷**（作者）：AI 版权声明 / 第三方素材声明 / 导出版权附页 / 版权证书 / 双生角色告知 —— 入口：创作者中心 → 法律

**阅读载体**：legal-view.html?doc=XXX（手机版壳 + 在线 md 渲染），2026-09-12 审查确认 7 个被引用文书全部可达、0 404。
**铁律**：第三方产品名（橙光/原神/星野等）0 出现于 UI；创作者法律只在创作 Tab；通用法律只在设置页。

## 11. 常见问题 FAQ 与故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 点「进入小说世界」提示「制作中」 | 该公版书尚未建世界（当前只有三国演义），v5.21+ 陆续开放，非故障 |

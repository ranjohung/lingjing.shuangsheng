## 0. 30 秒极速理解

**灵境 · 双生 = 30 题材小说 + 自动生成沉浸剧情 + AI 辅助创作 + 商业化 4 大系统**

```
客户上传小说 ──→ 自动解析（章节/角色/场景/高光）
                ──→ 自动生成沉浸剧情（场景+立绘+对话+选项）
                ──→ AI 辅助填表（22 字段模板）
                ──→ 自动判定版权分层（L1-L4）
                ──→ 自动质量审核（5 维度）
                ──→ 自动上架（22 收费点 + 3 级改编授权）
                ──→ 用户游玩 + 创作者收益分成
```

## 1. 产品是什么

### 1.1 定位
**一个角色，两种人生**——在故事里经历命运，在现实中陪伴你。

灵境 · 双生（Lingjing · Dual Souls）是一个 **AI 辅助的沉浸剧情式小说平台**，让用户上传任何题材的小说后，系统自动把它变成可玩的多结局沉浸剧情游戏，并提供创作者经济 + 质量审核 + 版权分层一站式服务。

### 1.2 核心能力
1. **30 题材全覆盖** — 玄幻/仙侠/都市/校园/历史/军事/游戏/科幻/灵异/悬疑/二次元/古言/现言/同人文/武侠/末世/赛博/无限流 等 30 大类
2. **上传即生成** — 客户贴文本，系统自动识别章节、角色、场景、高光
3. **沉浸剧情对话样式** — 全屏场景 + 角色立绘 + 底部对话框 + 打字机 + 悬浮选项 + 数值跳动
4. **AI 辅助填表** — 22 字段模板库，🤖 帮我写 2-5 个候选
5. **4 级版权分层** — L1 AI辅助 / L2 人机协作 / L3 作者主导 / L4 纯人工
6. **5 维质量审核** — 叙事 / 角色 / 文学 / AI味 / 合规
7. **22 种收费点 + 5 档作者等级** — 平台建议 50-500 灵晶/点，10-5000 范围
8. **3 级改编授权** — A 全版权 (60%) / B 单品类 (70%) / C 自主 (90%)

### 1.3 用户角色
- **客户/读者**：浏览 30 题材、上传自己的小说、玩沉浸剧情对话
- **创作者**：管理自己的小说、设定收费点、查看收益、申请改编授权
- **平台运营**：审核上架申请、处理侵权投诉、管理法务入口
- **开发团队**：本地原型测试 + 后续真后端迁移

## 2. 5 个核心角色和 4 步体验

### 2.1 体验路径（推荐顺序）

#### 路径 1：客户体验（最快 5 分钟）
1. 打开 `product-preview.html` → 滚动到 "30 题材库"
2. 点击 "📖 打开 30 题材库" → 进入 `library.html`
3. 浏览 30 题材卡，点击任一已上传的题材（带 "N 本" 角标）→ 自动滚动到已上传小说
4. 点击小说卡 → 进入 `plot-runner.html?novelId=xxx` → 玩沉浸剧情对话

#### 路径 2：创作者体验（10 分钟）
1. 进入 `commerce.html` → 顶部"选择小说"选 demo_palace
2. 5 个 section 自动加载：
   - ① 版权分层 → 点 "🔍 重新评估版权分层"
   - ② 收费点 → 点 "+ 新建收费点" 试填表单
   - ③ 收益看板 → 自动汇总
   - ④ 质量审核 → 点 "🔍 重新评估质量"
   - ⑤ 改编授权 → 点 "+ 申请改编授权"
3. 顶部任意字段旁的 🤖 按钮 → 触发 AI 辅助填表弹层

#### 路径 3：产品体验（5 分钟）
1. 打开 `product-preview.html`
2. 顶部"试玩沉浸剧情对话样式 · 锦绣未央" → 跳到 `plot-runner.html?novelId=demo_palace`
3. 顶部"体验商业化 4 大系统" → 跳到 `commerce.html`

#### 路径 4：3D 体验（10 分钟）
1. 打开 `product-preview.html` → 滚动到 "3D 真机" 章节
2. 点 "▶ 立即进入 3D 世界" → `game-3d.html`
3. 选题材（雨夜凉亭 / 教室走廊 / 霓虹街 / 客厅暖灯 / 仙山之巅）→ 玩 3D

#### 路径 5：上传自定义小说（15 分钟）
1. 进入 `library.html` → 点右上角 "＋ 上传小说"
2. 选题材 → 贴文本 → 填元数据 → 点 "一键解析"
3. 系统跳到 `novel-edit.html` → 可编辑节点/角色/选项
4. 点 "▶ 试玩" → `plot-runner.html`

### 2.2 核心操作快捷键（沉浸剧情对话内）
- **点击屏幕任意位置** — 推进对话（打字机加速）
- **点击选项按钮** — 选择分支（带 fx 数值标签）
- **F** — 与角色互动（3D 世界）
- **W/A/S/D** — 走动（3D PC 模式）
- **Esc** — 关闭输入框 / 关闭模态

## 3. 9 个页面完整使用指南

### 3.1 library.html（30 题材库首页）

**URL**：`output/preview/library.html`

**功能**：
- 30 题材全分类展示
- 搜索框（题材/小说名/角色）
- 筛选 chips（全部/已上传/空仓）
- 4 个 stats 指标卡（题材总数/已上传/已生成游戏/完成结局）
- 我的小说世界网格（含空仓提示）
- 30 题材卡片墙
- URL 参数：`?genre=xxx` 自动筛选并滚动到对应题材

**关键交互**：
- 点击搜索框 → 输入关键词实时筛选
- 点击 chip → 切换"全部/已上传/空仓"视图
- 点击题材卡 → 进入对应题材小说列表（或上传向导）
- 点击小说卡 → 进入沉浸剧情对话
- 点击右上角 "＋ 上传小说" → 上传向导

**顶栏**：
- 灵境 · 双生 logo → 回首页
- "小说世界" → 当前页（高亮）
- "🎮 5 题材老版" → 跳 game-3d.html
- "🏛️ v5.8 旧版" → 跳 redesign.html
- "📖 N 本小说" → 实时计数
- "＋ 上传小说" → 上传向导

### 3.2 novel-upload.html（4 步上传向导）

**URL**：`output/preview/novel-upload.html?genre=xxx`（可预选题材）

**4 步流程**：
1. **选题材** — 30 题材网格，点击高亮 → 下一步
2. **贴文本** — 大文本框，至少 2000 字 → 系统尝试自动解析
3. **元数据** — 标题（必填）/ 作者（可选）/ 封面图（可选）
4. **一键解析** — 生成 plotTree（nodes/chars/endings/sceneSettings）+ 覆盖审计

**关键交互**：
- 每步都有 "← 上一步 / 下一步 →"
- Step 4 自动跳到 `novel-edit.html?novelId=xxx`
- 解析失败可手动调整

### 3.3 novel-edit.html（剧情编辑器）

**URL**：`output/preview/novel-edit.html?novelId=xxx`

**3 个 Tab**：
- **节点（Nodes）** — 树状展示所有剧情节点，点击编辑
- **角色（Chars）** — 列表展示已识别角色，可调整名字/角色定位
- **结局（Endings）** — 4 稀有度（LEGENDARY / EPIC / RARE / COMMON）展示

**关键交互**：
- 顶部覆盖审计（chapters/chars/highlights 全覆盖度）
- "▶ 试玩" → plot-runner.html
- "💾 保存" → localStorage 持久化
- "🗑 删除" → 清空

### 3.4 plot-runner.html（沉浸剧情对话运行器）

**URL**：`output/preview/plot-runner.html?novelId=xxx`

**核心 UI 组件**：
- **全屏场景背景**（淡入切换）
- **角色立绘**（左右或居中，占屏 40-60%）
- **顶部菜单栏** — 7 按钮（自动/快进/历史/存档/读档/设置/编辑）
- **底部对话框**（半透明黑底 + 角色名 + 打字机文字）
- **悬浮选项按钮**（蓝绿色 + fx 数值标签）
- **状态数值条**（信任/亲密/声望 + 覆盖审计）
- **章节标题过场**（古色古香 2.2s）
- **结局模态**（LEGENDARY/EPIC/RARE/COMMON 4 稀有度）

**关键交互**：
- 点击对话框 → 推进下一句（打字机加速）
- 点击选项 → 分支跳转 + 数值跳动
- 顶部"📜 历史" → 最近 50 句对话
- 顶部"💾 存档" → 5 槽位存档
- 顶部"⚙ 设置" — 打字机速度（10-120ms）/ 背景音乐音量
- 顶部"📝 编辑" → 跳回 novel-edit.html

### 3.5 commerce.html（商业化设置）

**4 大系统一站式**：

## 5. 商业化 4 大系统使用手册

### 5.1 系统①：AI 辅助填表

**触发**：任意表单字段旁的 🤖 按钮
**流程**：
1. 点击 🤖 → 弹出候选层（2-5 个）
2. 选项数量动态：使用 <5 次给 2-3，5-20 给 3-4，>20 给 4-5
3. 可点击"换一批"重新生成
4. 可点击"我来说"自由输入
5. 选中候选 → 自动填入字段

**22 字段模板库**（5 类）：
- 基础信息（4）：书名 / 一句话简介 / 主题 / 基调
- 世界格局（4）：力量体系 / 核心冲突 / 主要势力 / 时代背景
- 人物小传（5）：性格特点 / 核心秘密 / 语言指纹 / 人物关系 / 行为动机
- 场景卡（3）：场景目标 / 情绪曲线 / 关键细节
- 对话场景卡（3）：对话目标 / 情绪基调 / 关键信息
- 收费点（3）：定价理由 / 触发条件 / 用户价值

### 5.2 系统②：版权分层（4 级）

**判定指标**：
- AI 生成字数占比
- 作者修改率
- 表格填写完整度
- AI 提问使用率

**判定规则**：
| 层级 | AI 占比 | 修改率 | 导出 | 商用 |
|---|---|---|---|---|
| L1·AI 辅助 | >70% | <20% | 50 灵晶 | 2000 |
| L2·人机协作 | 40-70% | 20-50% | 30 灵晶 | 1000 |
| L3·作者主导 | <40% | >50% | 免费 | 500 |
| L4·纯人工 | <10% | — | 免费 | 免费 |

**动态证书**：根据层级生成不同版权证书文本。

### 5.3 系统③：22 种收费点

**5 大类**：
- 剧情锁（5）：主线锁 / 番外锁 / 角色线锁 / 隐藏剧情锁 / 真结局锁
- 属性道具（5）：好感度 / 属性加成 / 金钱 / 声望 / 全档通用
- 卡牌收集（4）：角色卡牌 / CG 卡牌 / 命运卡牌 / 限定收藏
- 外观装饰（5）：角色服装 / 场景皮肤 / 聊天气泡 / 头像框 / 称号
- 功能解锁（3）：上帝视角 / 好感度可视化 / 路线图解锁

**价格区间**：10-5000 灵晶，平台建议 50-500
**作者分成**：
- L1 青铜 50% / L2 白银 60% / L3 黄金 70% / L4 钻石 75% / L5 传奇 80%
- 阶梯加成：月流水 1000 → 60%，5000 → 70%，20000+ → 80%

### 5.4 系统④：质量审核 + 改编授权

**5 维质量评估**：
- 叙事质量 30%（流畅度/连贯性/节奏/伏笔兑现）
- 角色质量 25%（一致性/成长弧光/对话自然度）
- 文学质量 20%（表现力/感染力/创新性）
- AI 味检测 15%（AI味指数 ≤40）
- 合规性 10%（敏感词零容忍）

**等级与上架**：
- S 级 ≥4.5 → 优先推荐
- A 级 4.0-4.4 → 正常上架

## 9. 常见问题 FAQ

### Q1：如何上传我的小说？
**A**：进入 `library.html` → 点右上角 "＋ 上传小说" → 4 步向导（选题材 → 贴文本 → 填元数据 → 一键解析）。建议文本 ≥2000 字。

### Q2：解析失败怎么办？
**A**：检查文本是否含完整章节标题（如"第一章"）。如果自动识别角色失败，可去 `novel-edit.html` 手动调整。

### Q3：如何修改已经上传的小说？
**A**：在 `library.html` 点击对应小说卡 → 右上角"📝 编辑"按钮 → 进入 `novel-edit.html`。

### Q4：如何设置收费点？
**A**：进入 `commerce.html` → 选小说 → "② 收费点" → "+ 新建收费点" → 选 5 大类 22 种 → 填价格（10-5000 灵晶）。

### Q5：版权分层会自动判定吗？
**A**：会。系统根据 AI 生成占比、修改率、表格完整度、AI 提问使用率自动判定 L1-L4 层级。也可手动点"🔍 重新评估"。

### Q6：可以商用我创作的作品吗？
**A**：可以。在 commerce.html "⑤ 改编授权" 申请 3 级授权（A 全版权 / B 单品类 / C 自主）。分成 60%-90% 归创作者。

### Q7：怎么删除一本小说？
**A**：在 `library.html` → 鼠标悬停在小说卡 → 右上角出现删除按钮。或在 `novel-edit.html` → 顶部"🗑 删除"。

### Q8：30 题材都有 demo 吗？
**A**：当前只有 5 部 demo（古言/悬疑/奇幻/科幻/校园），剩余 25 题材待补。

### Q9：能离线使用吗？
**A**：能。所有数据本地 localStorage，无网络依赖。但 Tailwind/FontAwesome CDN 首次需要联网。

### Q10：数据安全吗？
**A**：本地浏览器存储，100% 私密。但换浏览器/清缓存会丢失。建议定期导出备份（DevTools → Application → Storage）。

## 10. 故障排查

### 故障 1：点击题材卡 404
- **症状**：点击 library.html 上"古言·宫斗 1本"卡 → 跳转到不存在的 novel-list.html
- **原因**：v5.14 之前版本残留 bug
- **修复**：v5.15 已修复，改跳 `library.html?genre=guding#novel-grid`

### 故障 2：沉浸剧情对话背景图不显示
- **症状**：进入 plot-runner.html 后场景全黑
- **原因**：fade-in CSS 缺少 `forwards`（动画结束后 opacity 回 0）
- **修复**：v5.13 已修复（`.fade-in { animation: ... forwards; }`）

### 故障 3：AI 辅助弹层空白
- **症状**：点 🤖 按钮 → 弹层显示但无选项
- **原因**：使用次数过多或模板库空
- **修复**：刷新页面 / 换一批 / 我来说手动输入

### 故障 4：commerce.html 截图超时
- **症状**：Playwright 截图卡 30s
- **原因**：Google Fonts 加载慢
- **修复**：等待 30s 后正常显示，或部署时改本地 woff2

### 故障 5：3D 角色加载慢
- **症状**：game-3d.html 进入场景后角色迟迟不显示
- **原因**：.glb 文件大（2-5 MB）
- **修复**：v5.11 已用 Blender 压缩 + GLTFLoader 优化

### 故障 6：localStorage 满
- **症状**：上传新小说失败
- **原因**：localStorage 配额约 5-10 MB
- **修复**：删除旧小说 / 浏览器设置清理

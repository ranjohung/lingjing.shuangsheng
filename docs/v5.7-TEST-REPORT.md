## 1. 音效系统（WebAudio 零依赖）

### 5 题材 BGM
- **pavilion** — C 大调五声 + 雨夜白噪 + 远雷（bpm 64）
- **classroom** — C 小调 + 教室环境嗡嗡（bpm 88）
- **neon** — 蓝调小六 sawtooth + 霓虹 bandpass 滤波（bpm 120）
- **livingroom** — 温暖低音 sine + 暖灯嗡 + 钟表（bpm 76）
- **xianxia** — 仙侠宫商 + 风铃（bpm 72）

每题材 8 秒一个循环，setInterval 驱动，与 switchScene 挂钩自动切换。

### SFX
- **click** — 选项 click 880→1320Hz 上行
- **swoosh** — 220→880Hz 推镜
- **ping** — 关系值变化（正负音色区分）
- **ending** — 4 音钟声（按稀有度 LEGENDARY/EPIC/RARE/COMMON）
- **chapter** — 196→261→329Hz 三音过场

### 环境音（不静音时）
- pavilion：低通白噪雨声 + 远雷
- classroom：环境嗡嗡 + 远处铃声
- neon：120Hz bandpass 霓虹嗡嗡
- livingroom：80Hz 暖灯嗡 + 钟表
- xianxia：880~1568Hz 风铃

### 静音开关
HUD 顶栏右上「🔇/🔊」按钮，首次点击解锁 AudioContext（Chrome autoplay 政策）。

## 3. 章节过场动画

### 5 个章节
- 1. 雨夜·重逢（pavilion · 紫蓝渐变）
- 2. 午后·走廊（classroom · 青绿渐变）
- 3. 二十三层（neon · 青紫渐变）
- 4. 深夜·留灯（livingroom · 金粉渐变）
- 5. 仙山·之巅（xianxia · 紫青渐变）

### 动画
- 全屏覆盖层：径向暗渐变 + 主色径向渐变
- 文案：第 N 章（大字 14px + 22px 数字） → 章名（48px 大字 + 18px shadow）→ 副标题
- 触发：进入新场景时首次 2.6s，重复 1.4s
- 结局过场：金色调「结局」字样 + 章名 + 副标，2.8s 后消失

### SFX 联动
过场开始 200ms 后自动播放 chapter 三音 SFX。

## 4. 环境强化

### 程序化纹理（无需外部资源）
- **灯笼光晕 sprite** — 暖色径向渐变（粉→橙→透明），pavilion 3 颗 + xianxia 3 颗 + livingroom 2 颗
- **教室窗外光束** — 暖色线性渐变 planeGeometry，classroom 2 道斜光

### 场景参数调整
- **FogExp2 雾密度** 0.04 → 0.06（全局），加 fog:true 到雨粒子材质
- **雨幕粒子** color 0xaabbdd → 0xdde6f5，size 0.07 → 0.10，opacity 0.55 → 0.75
- **Bloom** 已生效（pavilion 灯笼 / neon 屏幕 / livingroom 暖灯）

### enhanceScene 钩子
在 5 个 build 函数（pavilion/classroom/neon/livingroom/xianxia）return root 前注入 `enhanceScene(name, root)`，零侵入。

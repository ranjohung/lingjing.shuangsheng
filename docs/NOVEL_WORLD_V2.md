配色：夜青#101d2b、湖青#234653、月白#f1efe6、淡金#d3bb85、雾灰#9db0bf；标题宋体，控件系统无衬线。布局为顶部轻菜单—全屏舞台—底部通栏对白，场景而非仪表盘占主视觉。移动端保持演出舞台，菜单可横滚，文字可完整滚动。

## 需求与顺序
1. NW-01 先实现世界入口、独立心屿入口、全屏演出舞台、阅读/探索切换、打字机、自动推进、全文历史、本地存读档；导入原稿可进入演出阅读。演出样例明确标识原创演示，不能称原著或AI生成。
2. NW-02 不可变canon_anchors绑定source版本/hash/span；自动分段须无遗漏、无重叠，场景/人物语义抽取经作者确认。全部锚点串联必须等于原稿，包括空白。分页演出不等于语义场景切分。导入稿未配置美术时用明确标注的通用背景，不虚构出场人物。
3. NW-03 divergence_records按用户/会话/源版本隔离，记录选择、世界快照、约束、2–3节点收敛目标及校验结果。三层校验含世界规则/人物一致性/目标收敛，并校验历史事实。真实模型未接不假装自由输入成功。
4. NW-04 探索热点、推荐行动、自由输入由有权限的锚点配置提供；骰子服务端生成并记录，天然1/20与修正后阈值区分。只改变支线/物品/NPC反应，不改原文。体力0–50、健康/容貌-20–20、名望-200–200、智谋/武勇/共情0–20是新世界属性，不直接覆盖旧吕布存档字段。
5. NW-05 世界快照包含时间/位置/属性/背包/NPC好感信任情绪/事件/支线/原稿进度，模式切换不重置。因果提示是独立UI注释，不能插入或改写原文。
6. NW-06 双界角色延续继续依赖既有权利、关系及记忆契约，不以按钮假装带出已完成。

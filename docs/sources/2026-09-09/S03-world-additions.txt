第一部分：World OS / AI Novel / Live Your Novel 产品设计（【新增】核心功能模块）

1.1 功能定义

正式名称： 灵境 · 无限世界（Infinite World Engine）

核心功能： 创建一本小说 → AI生成完整世界 → 用户进入小说 → 自由生存 → 改变剧情 → 世界持续演化 → 自动生成属于用户自己的小说。

三个核心系统：

系统 职责 说明
World OS 世界操作系统 管理时间、地图、角色、势力、规则、经济、天气、事件、历史
AI Novel Engine AI小说生成引擎 自动生成小说圣经、角色小传、章节、伏笔、结局
Live Your Novel 进入小说世界模拟 用户创建角色进入世界、自由行动、改变剧情

1.2 产品定位

产品不是： AI写小说工具 / AI聊天软件 / 文字冒险游戏

产品是： AI世界模拟与小说体验平台

核心循环：

```
创建世界 → 创建小说 → AI生成角色 → AI生成世界 → AI生成故事
    ↓
用户进入世界 → 自由行动 → 世界产生变化 → 角色产生变化
    ↓
关系产生变化 → 时间线分裂 → AI继续生成故事 → 自动形成小说
```

1.3 用户核心爽点设计

爽点 说明
成为故事主角 用户选择人生（原著主角/重要角色/新角色/隐藏身份/普通NPC/观察者）
命运可以改变 用户救下必死角色，世界产生连锁反应
角色对我有记忆 角色记住共同经历，产生“被记住爽感”
专属剧情 每个用户拥有自己的小说（恋爱/敌人/从未见过/杀死角色）
隐藏剧情 隐藏角色/身份/结局/任务/地图/真相/恋爱路线
攻略角色 多维关系状态（信任/亲密/尊重/吸引/冲突/理解/共同历史）
收集 角色图鉴/剧情图鉴/CG/回忆/结局/成就/世界秘密
多周目 保留当前世界，创建平行时间线

1.11 AI调用流程（【补充】完整的AI叙事调用链）

```
【用户输入】"我偷偷跟踪他"

【Step 1】Action Parser（LLM - Cheap Model）
输入：用户原始文本
输出：{"intent": "follow", "target": "character_001", "style": "secret", "risk": "medium"}

【Step 2】World Rule Check（程序规则引擎）
检查：世界规则是否允许？用户当前状态是否允许？
输出：pass / fail + 原因

【Step 3】Probability Engine（程序计算）
成功率 = 用户潜行技能(45) + 环境遮蔽(20) - 目标警觉度(30) = 35%

【Step 4】Event Engine（程序）
生成事件：成功→"发现秘密"事件；失败→"被发现"事件

【Step 5】World Update（程序）
更新：用户位置、目标状态、关系值、世界状态

【Step 6】Story Director（LLM - Medium Model）
输入：World State + Character State + Event Result + Relationship
输出：故事方向建议 + 叙事文本 + 是否触发角色路线

【Step 7】Narrative Generator（LLM - Medium Model）
输入：Story Director的建议 + 世界状态摘要 + 最近对话
输出：具体叙事文本

【Step 8】Editor Agent（LLM - Cheap Model）
检查：与历史记录冲突？角色OOC？违反世界规则？
修正后重新输出
```

1.14 验收标准（【补充】每个Sprint可量化指标）

Sprint 1（World Core）

验收项 标准
创建世界 用户输入一句话，AI在30秒内生成完整世界DNA
世界规则 支持5种以上规则类型，规则冲突时系统能检测并提示

Sprint 2（Character Simulation）

验收项 标准
角色自主行为 5个NPC同时自主运行，每个每小时产生至少1个决策
角色目标 NPC能根据当前状态调整子目标

Sprint 3（Event Engine）

验收项 标准
因果链 用户行为能在3步内触发连锁反应
事件追溯 任何事件都能追溯到源头原因

Sprint 4（Story Engine）

验收项 标准
主线推进 用户不行动时，世界主线仍在推进
角色路线 用户与特定NPC互动≥10次后，触发角色专属剧情

Sprint 5（Timeline）

验收项 标准
分支保存 关键选择点自动生成Save Point
平行世界 用户可从同一Save Point创建2个以上不同分支

Sprint 6（Novel Engine）

验收项 标准
章节生成 用户游玩1小时后，系统自动生成至少1章小说
小说质量 Editor Agent检测到OOC/逻辑冲突的次数 < 3次/章

Sprint 7（Live Your Novel）

验收项 标准
进入世界 用户从选角到进入世界 < 3分钟
自由行动 用户输入任意行动系统都能响应

Sprint 8（Novel Sync）

验收项 标准
双向同步 小说修改 → 世界变化；世界变化 → 小说更新

Sprint 9（3D Integration）

验收项 标准
场景同步 World OS输出的场景状态能正确驱动3D场景加载

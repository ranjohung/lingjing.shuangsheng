《灵境 · 双生》— 功能区分功能细节开发文档 V2.0（用户 2026-09-15 提供原文归档）

========================================================================
一、核心新增：启动逻辑（最高优先级）
========================================================================
1. 第一次登录（新用户/新设备）：
   → 直接进入首页，无打招呼界面
2. 第二次登录及以后（老用户回访）：
   → 进入 APP 后，陪伴AI（心屿入驻角色）全屏打招呼界面
   → 问候语 + 角色形象 + [进入灵境] 按钮，点击后进入首页
   → 每次会话只出现一次

========================================================================
二、首页（产品体验主页）分功能细节
========================================================================
1. 顶部：头像入口（进我的）、签到入口（每日签到领灵晶）
2. 签到规则：第1天4灵晶/第2天4/第3天6/第4天8/第5天10/第6天12/第7天25，
   断签重新计（从第1天开始），7天一循环
3. 四个快捷入口：创作中心 / 世界书架 / 心屿陪伴 / 我的钱包
4. 内容板块：热门推荐（作品轮播）/ 官方公告 / 最近在读
5. 底部 5 Tab：首页 / 世界 / 心屿 / 创作 / 我的

========================================================================
三、世界（世界书架/公版库）
========================================================================
1. 世界书架：全部作品列表（公版书 + 用户上传作品）
2. 分类筛选：题材标签（古风/玄幻/悬疑/科幻/都市/历史等）
3. 搜索框：按书名/作者搜索
4. 作品卡：封面 + 书名 + 作者 + 题材标签 + 评分 + [进入世界] 按钮
5. 上传入口：[+ 上传我的小说]（走 V24 上传质检流程）

========================================================================
四、心屿（AI陪伴）
========================================================================
1. 角色列表：已入驻的陪伴AI（含小说世界带出角色）
2. 聊天界面：聊天模式（心屿豁免"世界功能区禁止聊天"铁律）
3. 角色详情：性格标签 / 好感度 / 关系进度 / 互动入口
4. 新角色入驻引导

========================================================================
五、创作（创作者功能区 · 除小说辅助模拟器外）
========================================================================
1. 顶部工具栏：关闭/返回 + 草稿箱
2. 快捷创建区：创建智能体（周额度10次）/ 灵境工坊
3. 多媒体创作区：创建视频 / 创建图片 / 创建声音
4. 更多创建区：创建动态 / 复刻音色 / 创建灵念 / Agent创建
5. 我的作品 → 更名「编辑我的作品」（强调编辑管理属性）
6. 灵境工坊：等级 / 收益 / 作品管理 / 互动管理 / 模板库 / 数据看板

========================================================================
六、我的
========================================================================
1. 用户信息卡：头像/昵称/等级/灵晶+灵玉余额
2. 资产区：钱包 / 收益 / 提现
3. 创作管理：我的作品 / 草稿箱 / 收益明细
4. 通用：设置 / 实名认证 / 法律文档 / 关于
5. 我的双生：已带出的双生角色列表

========================================================================
七、范围说明
========================================================================
- 不含：小说辅助模拟器（V21 保留原设计）
- 不含：小说世界游戏（V22/V24 线）
- 不含：UI 设计稿
- 用途：基于产品需求文档 V2.0 检查 PRD 与开发计划的遗漏与错误，
  列出未完成清单，按优先级继续开发
========================================================================

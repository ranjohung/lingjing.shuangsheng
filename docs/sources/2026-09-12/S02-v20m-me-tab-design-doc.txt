《灵境 · 双生》— "我的"功能区完整设计文档
（V20-M 需求原文存档 · 永不修改 · 2026-09-12）

用途：直接发给 AI 开发助手执行。严格按照以下要求实现，不要自由发挥。

一、页面整体结构

"我的"Tab 从上到下分为七个区块：
1. 个人信息区
2. 资产总览区
3. 我的内容区（我的作品、我的收藏、我的角色）
4. 创作者中心区（仅创作者可见）
5. 订阅与消费区
6. 设置区
7. 法律与帮助区

二、个人信息区
2.1 显示内容
· 用户头像（可点击更换）
· 用户名（可点击编辑）
· 用户 ID
· 个性签名（可编辑）
· 实名认证状态（已认证/未认证）
· 编辑资料按钮
2.2 点击编辑资料后进入
· 修改头像 / 修改用户名 / 修改个性签名 / 修改性别 / 修改生日 / 修改所在地
· 绑定手机号 / 绑定邮箱 / 实名认证入口

三、资产总览区
3.1 横向三个资产卡片：💎 灵晶余额 / 🪙 灵玉余额 / ⭐ 收藏数量
3.2 点击灵晶/灵玉进入钱包页：余额 + 充值 6 档（6/30/68/128/328/648 元）+ 消费记录（最近 50 条）+ 充值记录 + 灵玉获取记录（签到、任务、活动）
3.3 点击收藏进入收藏页：收藏的小说世界 / 角色 / 卡牌 / 动态 + 分类筛选 + 取消收藏

四、我的内容区
4.1 我的作品（仅创作者可见）：已发布 / 草稿箱 / 审核中 / 已下架，每部显示封面、书名、字数、状态、收益，点击进入作品管理页
4.2 我的角色：我创建的 + 双生角色，显示头像、名字、来源角标、亲密度，点击进角色详情
4.3 我的世界：正在游玩 + 已完成，显示封面、书名、进度百分比、最后游玩时间，点击继续游玩
4.4 我的卡牌：已收集命运卡牌，按稀有度（普通/稀有/史诗/传说/限定）与来源筛选，详情可分享/设为背景

五、创作者中心区（仅创作者可见）
5.1 创作者等级：L1 青铜 / L2 白银 / L3 黄金 / L4 钻石 / L5 传奇 + 分成比例 + 升级进度条
5.2 收益总览：总收益 / 待结算 / 已提现 / 本月收益 + 收益明细入口
5.3 收益明细：按作品 / 按收费点 / 按时间 + 导出收益报表
5.4 提现入口：可提现余额 / 提现申请 / 提现记录 / 提现规则说明
5.5 创作数据看板：阅读量 / 进入世界次数 / 平均游玩时长 / 角色受欢迎程度 / 章节退出率

六、订阅与消费区
6.1 当前订阅：计划（Free/月卡/星卡）+ 到期时间 + 续费按钮 + 权益说明
6.2 订阅管理：升级订阅 / 取消订阅 / 订阅历史
6.3 消费记录：灵晶消费明细 / 灵玉消费明细 / 订阅消费记录

七、设置区
7.1 账号设置：修改密码 / 绑定解绑手机邮箱 / 第三方账号（微信、QQ、Apple ID）/ 实名认证 / 账号安全
7.2 隐私设置：个人资料可见性 / 互动记录可见性 / 收藏可见性 / 在线状态可见性 / 数据授权管理 / 隐私政策查看
7.3 通知设置：系统通知 / 角色主动消息 / 世界更新提醒 / 活动通知 / 创作者收益通知
7.4 使用偏好：语言 / 主题（深色浅色）/ 字号 / 自动播放 / 语音设置
7.5 数据管理：数据导出 JSON / 清除缓存 / 记忆管理 / 对话历史管理

八、法律与帮助区
8.1 法律文件：用户协议 / 隐私政策 / 未成年人禁止使用声明 / AI 生成内容免责声明 / 侵权投诉流程
8.2 帮助与反馈：FAQ / 意见反馈 / 举报入口 / 客服联系方式
8.3 关于我们：版本号 / 更新日志 / 官方社群入口 / 商务合作联系方式

九、退出/注销账号
· 退出账号按钮 / 注销账号按钮（页面底部）
· 注销前提示：30 天后悔期，期间可恢复
· 注销后数据处理说明

十、执行要求
1. 底部导航栏 5 个 Tab 保持不变
2. 七区块结构 + 全部子项
3. 所有文案使用灵境专属术语（灵晶、灵玉、心屿、双生等）

十一、验收标准（11 条）
1. 七区块结构清晰 2. 个人信息可编辑+实名状态 3. 资产三卡可跳转 4. 我的内容四入口 5. 创作者中心动态显示 6. 订阅计划+续费 7. 设置五组 8. 法律帮助全齐 9. 底部退出/注销 10. 灵境专属术语

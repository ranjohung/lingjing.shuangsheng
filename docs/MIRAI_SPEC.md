竞品“黄金结构”和具体分支数不作为行业事实引用；上述数字是项目目标。聊天中的法规条款、日期、公版译本和平台来源不视作已核实法律意见；上线前核验主管部门原文、版本授权和服务商资质。仅面向成年人是产品策略。低安全事件率不能代替合规验收。

## 工程原则
- Next.js App Router/TypeScript/Tailwind/Zustand + FastAPI；正式存储PostgreSQL/pgvector、SQLAlchemy/Alembic，Redis计数。
- 新故事模块位于apps/api/src/modules/story/。规则引擎裁决选项、属性、NPC关系、标志、路线、结局；AI仅润色叙事，不直接提交状态。
- 正式存档绑定作品版本、用户和身份；推进用revision、事务、幂等；回溯恢复全状态。
- 自建人物通过明确身份槽位进入已有剧本，不能仅改显示名称而声称任意角色模拟。首批槽位须给出身份与背景兼容说明；任意行动是后续增强。
- 开发内存会话必须明确提示重启丢失，不算正式存档。正式表变更一律Alembic。
- 每个需求需实现路径、测试证据、剩余缺口；模拟、界面、样例不等于生产完成。

## 一、变更背景与目标

### 1.1 当前问题（v6.4.1 → V17 → V18 收敛）

| 版本 | 完成度 | 缺口 |
|---|---|---|
| **v6.4.1** | 5 Tab 共享壳 + 4 主 Tab 页面 + 沉浸页返回按钮 | 首页只是"问候 + 继续游玩 + 今日推荐" 3 板块，缺签到/4 快捷/陪伴动态/世界更新/热门活动 |
| **V17** | 世界功能区 + 心屿功能区重构（Q1-Q11 全锁定） | 心屿未实现 [创]/[双] 角标、未实现职业问答/免责声明/弹窗 |
| **V18** | 整合 + 收尾 | 待开发 |

### 1.2 V18.0 目标

1. **首页重做**：4 层结构（状态栏/签到/快捷入口/推荐流）+ 4 推荐板块（今日推荐/陪伴动态/世界更新/热门活动）
2. **心屿重做**：5 子标签 + 陪伴子筛选 + 角色统一展示 + [创]/[双] 角标 + 首次进入弹窗 + 角色详情页来源标签 + 免责声明 + 职业问答 + 双生[进入世界]按钮
3. **小说世界 plot-runner 重做**：6 层叠加（场景/立绘/对话框/选项/工具栏/属性）+ 30ms 打字机 + 选项悬浮 + 数值跳动 + 地图探索 + 系统菜单 + 10 存档槽 + 6 类结局
4. **世界功能区去橙光化**：心屿推/引路人/每周回响/创世杯/同频共振群/灵韵/灵晶/灵玉 双轨经济 + 5 档充值（6/18/58/128/328元）

### 1.3 V18.0 非目标（本次不做）

- ❌ 真 LLM 接入（保留 mock + `window.AIHelper` 钩子）
- ❌ 真支付接入（保留灵玉/灵晶档位 mock）
- ❌ 不动底部 5 Tab 结构和现有 shell-v64.css

### 5.9 职业问答能力（V16.0 3.7）

**所有角色**（无论自创/双生）只要设定了职业，就具备科普问答能力。

**可回答**：职业相关常识、科普、建议方向
**禁止回答**：具体诊断、开处方、法律意见、心理治疗方案

**敏感问题模板**（AI 必须遵守）：
```
用户："我胸口疼，是不是心脏病？"
AI（医生）："我理解你的担心，但我无法通过对话诊断身体状况。
请尽快去医院心内科就诊，如果疼痛剧烈请立即拨打 120。"
```

四要素：
1. 不编造答案
2. 明确告知能力边界
3. 建议咨询专业人士
4. 提供具体求助渠道（120/12348 等）

## 七、关键工程判断

1. **设计系统先行** — 不让各页面"各自一套"，先沉淀 ds-* 70+ 组件，下游页面只要 `<link>` 一行就拿到设计语言
2. **不改业务逻辑** — 21 张数据表不动 / demo seed 数据不动 / JS 模块逻辑不动
3. **mini style 块 ≤ 30 行** — 任何页面只能有极少量 page-level override（layout / metric 等）；样式进设计系统
4. **`<dialog>` 优先** — 替代 `alert()` / `confirm()` / 自定义 modal CSS
5. **`<dialog>` 双 modal** — 双界穿梭 modal 显示条件校验，"TA 已在家" modal 简短友好解释
6. **emoji 不滥用** — 1 屏最多 3 个 emoji，UI 信号而非装饰

**核心交付**：灵境 · 双生的视觉语言从"三代并存"升级到"v6 设计系统一统" — 后续 14 个页面只要 link 同一份 css，自动获得一致观感。

## 一、命名博弈与决策

| 候选 | 维度 | 决策 |
|---|---|---|
| 知己（v5.19 自定名） | 工程师视角：亲切、好记 | ❌ 已被设计文档覆盖 |
| **心屿**（v5.20 用户定名） | "心"指情感连接，"屿"指独立空间；与品牌"灵境 · 双生"同东方意境；与小说世界"无限世界"形成对仗 | ✅ 官方命名 |
| 伴界、灵栖、双生 | 设计文档列出的备选 | ❌ 心屿最佳 |

**决策**：「**心屿**」（Xin Yu / Heart Island）— 心灵的岛屿，每个角色都是用户心中的一座岛屿，可随时停靠、休憩、生活。

**改名波及范围**（4 HTML + 1 CSS + 1 库入口）：
- `companion.html` → **`heart-island.html`**（文件重命名，主页承载官方功能名）
- `chat.html` / `memory.html` / `profile.html` 内部所有"知己"→"心屿"，链接全部改回 `heart-island.html`
- `library.html` 顶部 nav 与移动底部 tab bar：`💞 知己` → `🏝️ 心屿`，href 改 `heart-island.html`
- `design-system.css` 注释里 2 处"知己" → "心屿"（v5.20 标识）

**小说世界中"知己"结局不动**：`redesign.html` 第 974/1196/2254 行的黛玉"知己"结局是红楼梦剧情特定保留词，与功能名无关。

### 3.2 主角色大卡（核心新增）

**结构**（按视觉权重自上而下）：

1. **头部**：64px 渐变头像 + 姓名 + 阶段胶囊（"知己"，琥珀金底）+ 状态（在线/离线，绿点）
2. **6 阶段进度条**：`初识 → 熟悉 → 朋友 → 亲密 → 知己 → 灵魂伴侣`，当前 89% 处高亮 "知己"
3. **7 维关系仪表**：信任 90 / 亲密 75 / 熟悉 85 / 尊重 88 / 吸引 80 / 理解 82 / 共同历史 70（每行条 + 数字）
4. **3 个动作按钮**：
   - 主按钮：「💬 陪 TA 聊聊」 → chat.html
   - 次按钮：「🌐 进 TA 的世界」 → 双界穿梭弹窗（v5.21 接 API）
   - 灰色禁用：「🏡 TA 已在家」 → 提示"无需穿梭"

**视觉风格**：心色调（粉紫渐变 + 琥珀金光斑），8pt 网格，cubic-bezier(0.16, 1, 0.3, 1)。

### 3.3 双界穿梭 CTA + Info Modal

紧邻主角色大卡下方，点击弹 `<dialog>` 解释：

- **图 → 🏝**（小说 → 心屿）：亲密度 ≥ 80 + 个人线已解锁 + 800-3000 灵晶
- **🏝 → 📖**（心屿 → 小说）：随时进入角色所在小说主线，记忆贯通

**当前为草案 + 弹窗说明**：完整穿梭流程待 v5.21 接小说世界 API 后启用。

### 3.4 我的角色标题行

```
[我的角色]            [6 位已解锁] [+ 新建] [⚡ 从小说带出]
```

新建按钮 → v5.21 将打开 `character-create.html` 7 步 wizard。带出按钮 → 复用双界穿梭 CTA modal。

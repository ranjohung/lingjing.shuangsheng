## 一、变更背景与目标

### 1.1 当前问题（v5.20 现状）

| 现状 | 问题 |
|---|---|
| `library.html` 是世界入口，但底部没有 tab bar 概念，是单页全功能 | 用户进入后缺少全局归属感，无法快速切换到心屿、创作、我的 |
| `heart-island.html` 是心屿入口，是独立单页 | 与世界入口是平行页面关系，缺少"陪伴 vs 内容"的产品心智隔离 |
| 没有"首页"概念 | 新用户进入 App 第一眼看到的世界首页，缺乏"先看、再玩、再陪"的引导节奏 |
| 没有启动签到 | 用户开 App 直接进首页，缺少每日激励机制入口 |
| 角色来源在 UI 上没有显式区分 | 用户不知道某个角色是"自己创建的"还是"从小说带出来的" |

### 1.2 v17.0 目标

1. **底部 5 Tab 全局骨架**：所有页面都挂在 `🏠首页 / 📖世界 / 💬心屿 / ✨创作 / 👤我的` 之下，无论进入哪个页面都能一键回到 5 大功能区。
2. **世界功能区升级为内容货架**：从单页 `library.html` 升级为内容流（Banner + 四大金刚 + 双列瀑布流 + 分类侧边栏 + 筛选 + 同人区）。
3. **心屿功能区升级为关系中心**：从 4 个独立页面（`heart-island.html` / `chat.html` / `memory.html` / `profile.html`）升级为底部 tab 内嵌的 5 子标签（陪伴 / 精选 / 记忆 / 故事 / 搜索），角色来源显式区分（[创] / [双]）。
4. **启动签到**：每日打开 App 第一动作，7 天递增奖励，附带 4 个快捷入口。
5. **职业问答能力**：所有有职业设定的角色（自创 + 双生）都具备职业科普问答能力，敏感问题引导求助专业人士。

### 1.3 v17.0 非目标（本次不做的）

- ❌ 不动全局底部 5 Tab 的图标、文案、顺序
- ❌ 不动 v5.20 已落地的 21 张数据表结构（仅增量加 3 个字段）
- ❌ 不动 v5.18 已落地的创作者中心（`creator-center.html` / `creator-create.html` / `novel-ai-helper.html` / `commerce.html` / `novel-upload.html` / `novel-edit.html`）
- ❌ 不动 v5.20 已落地的 4 张心屿数据表（`heart_island_characters` / `dual_soul_bringout_records` / `daily_interactions` / `proactive_behaviors`）的核心 schema
- ❌ 不接真 LLM（保留 `window.AIHelper` 钩子）
- ❌ 不接真支付（保留 UI 与 localStorage 模拟）

## 二、全局底部导航栏（绝对保留）

### 2.1 规格

```
🏠首页  📖世界  💬心屿  ✨创作  👤我的
```

### 2.2 关键约束

| 约束 | 说明 |
|---|---|
| 固定 5 个 Tab | 不得增删、不得调整顺序 |
| 全局可见 | 无论进入任何页面（除启动签到弹窗等模态层外），底部 5 个按钮始终存在、可点击 |
| 当前 Tab 高亮 | 当前所在 Tab 用主色（紫琥珀 #A78BFA）高亮，其余用中性色 |
| 不影响子导航 | 顶部子导航标签（如世界功能区内的 7 个子标签）独立于底部 5 Tab，点击切换不触发底部 Tab 跳转 |

### 2.3 当前已有底部 tab bar 的复用

> **🔵 v6.4.1 复用提示**：项目已在 v6.4.1 落地 `output/preview/css/shell-v64.css`（5 Tab 共享壳，约 150 行），4 个主功能区页面已统一接入。**V17.0 不新建 tabbar 组件**，仅复用 v6.4.1 已落地的 `.tabbar` / `.tab`。

v5.19 已为 `library.html` 实现 `ds-bottom-tabs` 移动端底部 tab bar，v17.0 需要做的是：

1. **沿用 v6.4.1 已落地的 5 Tab 共享壳**（`shell-v64.css` 的 `.tabbar`），**不重复造轮子**
2. **active 配色**：首页红 #E94560 / 世界绿 #00B894 / 心屿紫 #6C5CE7 / 创作橙 / 我的默认（v6.4.1 已定义）
3. **新建页面（如 `character-detail.html`）直接接入该壳**

### 3.3 顶部子导航（7 项固定）

| # | 标签 | 行为 |
|---|---|---|
| 1 | **首页** | 显示 3.6 内容流（编辑推荐 + 热门佳作 + 最新完结）— **默认选中** |
| 2 | 排行榜 | 内容流切换为榜单视图（待定，与内容流卡片同卡片样式，按"灵韵"或"人气"排序） |

| 5 | 创世杯 | 内容流切换为创作者大赛作品 |

**点击行为**：标签切换下方内容流，**不跳转页面**，底部 5 Tab 不变。

### 3.4 主视觉 Banner 轮播区

| 规格 | 值 |
|---|---|
| 位置 | 顶部子导航栏下方 |
| 高度 | 屏幕高度的 32% |
| 宽度 | 100%（全宽） |
| 数量 | 最多 5 个 |
| 切换方式 | 左右滑动 + 自动轮播（间隔 5s） |
| 指示点 | 底部居中，圆点，当前页高亮 |
| 单张内容 | 图片（横版 16:9）+ 大标题 + 副标题 + 跳转链接 |
| 跳转 | 点击进入对应世界详情或活动页（v17.0 暂跳 `discover.html` 或占位页） |
| 预置主题 | 围绕"双生"概念 + 热门小说世界（5 张） |
| 后台可配置 | 图片 / 标题 / 副标题 / 跳转链接（v17.0 走 localStorage mock，后台配置 UI 待 v17.1+） |

### 3.5 四大金刚（功能入口）

横向 4 按钮，均分宽度（25% each）。

| # | 图标 | 文案 | 行为 |
|---|---|---|---|
| 1 | ⊞ | 全部分类 | 从左侧滑出分类侧边栏（3.7） |
| 2 | 📅 | 更新日历 | 内容流切换为日历时间轴（v17.0 mock） |
| 3 | 👑 | 经典必看 | 内容流切换为公版名著精选书单（v17.0 mock，复用 3.8 数据） |
| 4 | ✍ | 创作 | 跳到底部 Tab **✍创作**（`creator-center.html`） |

**视觉**：卡片式按钮，背景浅紫渐变，hover 抬升 2px。

### 3.6 内容流（默认"首页" tab）

**布局**：双列瀑布流（48% × 2 + 4% 间距），按板块切分。

**板块结构**：

| 板块 | 标题 | 右侧子标签 |
|---|---|---|
| 1 | 【编辑推荐】 | [最新] [完结] |
| 2 | 【热门佳作】 | [近期] [完结] [新作] [历史] |
| 3 | 【最新完结】 | [最近] [全部] |

**卡片规格**：

| 字段 | 值 |
|---|---|
| 宽度 | 48% |
| 封面图比例 | 高 = 宽 × 1.4（竖版） |
| 圆角 | 8px |
| 内容 | 封面图 / 书名 / 作者名 / 题材标签（1-2 个）/ 一句话简介 / 评分（⭐ 8.8 分）/ 字数（12.8 万字） |

**数据来源**：`js/db.js` 已有 `worlds` 表 + `discover.html` mock 数据。v17.0 新增统一封面/简介字段（若缺则用占位图）。

### 3.8 筛选结果页（点击分类标签后进入）

**顶部排序切换**：`本周灵韵 | 本周人气`（tab 切换样式）

| 类别 | 选项 |
|---|---|

- `编推`（编辑推荐红底白字）
- `完结`（绿底白字）
- `新作`（蓝底白字）

### 3.9 同人区（公版小说专区）

**入口**：顶部子导航第 6 项「同人区」

**数据来源**：v5.12 30 题材库中标记 `is_public_domain = true` 的世界（红楼梦 / 三国演义 / 西游记 / 水浒传 / 聊斋志异等）。

### 3.10 搜索子区（顶部子导航第 7 项 🔍）

**入口**：点击 🔍 → 顶部子导航下方出现搜索框（高度 48px）。

**搜索范围**：
- 作品名（模糊匹配）
- 作者名（模糊匹配）
- 题材标签

**结果展示**：双列瀑布流作品卡片，**无板块标题**。

## 四、心屿功能区详细规格

### 4.1 进入路径

底部 Tab **💬心屿** 点击 → 进入心屿功能区。

### 4.2 页面层级（自上而下）

```
┌─────────────────────────────────┐
│   [陪伴|精选|记忆|故事|🔍]       │  ← 4.3 顶部子导航（5 项）
├─────────────────────────────────┤
│  [全部|我创建的|双生角色]        │  ← 4.4 陪伴子筛选（仅"陪伴" tab 显示）
├─────────────────────────────────┤
│                                 │
│  ┌────────────┐  ┌────────────┐ │  ← 4.5 角色列表
│  │ [头像] [创] │  │ [头像] [双] │ │     （双列瀑布流）
│  │ 角色名     │  │ 角色名     │ │
│  │ 知己 89     │  │ 亲密 76    │ │
│  │ 最近消息... │  │ 最近消息... │ │
│  │ [聊天]      │  │ [聊天][进入世界]│
│  └────────────┘  └────────────┘ │
│                                 │
│        [+ 创建新角色]            │  ← 列表底部按钮
│                                 │
├─────────────────────────────────┤
│ [🏠首页 📖世界 💬心屿 ✨创作 👤我的]  ← 全局底部 5 Tab
└─────────────────────────────────┘
```

### 4.3 顶部子导航（5 项固定）

| # | 标签 | 行为 |
|---|---|---|
| 1 | **陪伴** | 显示 4.5 角色列表（含 4.4 子筛选）— **默认选中** |
| 2 | 精选 | 显示 4.6 精选角色瀑布流 |
| 3 | 记忆 | 显示 4.7 时间线记忆 |
| 4 | 故事 | 显示 4.8 双生角色带出记录 |
| 5 | 🔍 | 显示 4.9 搜索框 |

**点击行为**：标签切换下方内容，**不跳转页面**，底部 5 Tab 不变。

### 4.4 陪伴子筛选（仅"陪伴" tab）

| 按钮 | 行为 |
|---|---|
| 全部 | 显示所有角色（含 [创] + [双] + 官方预设）— **默认选中** |
| 我创建的 | 只显示 source_type = user_created |
| 双生角色 | 只显示 source_type = novel_brought_out |

### 4.5 角色列表（陪伴 tab 主体）

**布局**：双列瀑布流（48% × 2 + 4% 间距）。

**卡片内容**：

| 字段 | 说明 |
|---|---|
| 头像 | 64px 圆形 + 渐变 fallback |
| 来源角标 | 头像右上角小标签：`[创]` 蓝底 / `[双]` 粉底 |
| 角色名 | 1 行 |
| 关系阶段 + 亲密度 | 例："知己 · 89" |
| 最近消息预览 | 1 行截断 |
| 按钮区 | 所有角色都有 `[ 聊天 ]`；双生角色额外有 `[ 进入世界 ]`（点击跳转到该角色所在小说世界） |

**列表底部**：`[ + 创建新角色 ]` 按钮 → 打开 `character-create.html` 7 步 wizard（v5.20 TODO 中已规划）。

### 4.6 精选子功能区

**布局**：双列瀑布流角色卡片。

**数据来源**：v5.20 `heart_island_characters` 表中 `is_featured = true` 的角色。

**卡片交互**：点击进入角色详情或直接开始聊天。

### 4.7 记忆子功能区

**布局**：时间线（竖向，节点 + 连接线）。

**每条记忆**：

| 字段 | 值 |
|---|---|
| 时间 | 相对时间（"3 天前" / "刚刚"） |
| 来源角色 | 头像 + 角色名 |
| 记忆类型 | icon + 文字（"初次相遇" / "百次对话" / "关系升级" 等） |
| 记忆摘要 | 1-2 句 |
| 操作 | 查看 / 编辑 / 删除 |

**关系里程碑**：用醒目样式标记（如金色节点）。

### 4.8 故事子功能区

**说明**：仅展示双生角色（`source_type = novel_brought_out`）的带出记录。

**每条记录**：

| 字段 | 值 |
|---|---|
| 角色头像 + 名 | 头部 |
| 来自小说 | 《小说名》 |
| 共同经历 | "N 个转折点" |
| 进入按钮 | `[ 进入 TA 的世界 ]` → 跳转到 `discover.html` 或 `library.html` 对应世界详情 |
| 角色专属剧情入口 | `[ 专属剧情 ]` → 跳转到 `plot-runner.html` |

**空态**：自创角色不出现；用户若无双生角色，显示空态卡片 + 引导文案"完成小说互动，带出你的双生角色"。

### 4.9 搜索子功能区

**搜索框**：顶部 48px 输入框，placeholder："搜索角色名、职业、关键词"。

**搜索范围**：
- 角色名（模糊）
- 职业（精确）
- 关键词（匹配 personality_json 中的标签）

### 4.14 职业问答能力规范（所有角色通用）

**适用范围**：**所有**有 `occupation` 设置的角色（自创 + 双生 + 官方预设）。

**能力边界**：

| ✅ 可以回答 | ❌ 禁止回答 |
|---|---|
| 职业相关的常识科普 | 具体诊断（"你得了 XX 病"） |
| 职业相关建议方向 | 开处方 / 药方 |
| 职业相关经验分享 | 法律意见 / 判决预测 |
| 行业入门知识 | 心理咨询方案 / 治疗建议 |

**敏感问题处理流程**（AI 必须严格遵守）：

1. **不编造答案** — 不确定时明确说"我不确定"
2. **明确告知能力边界** — "这是 AI 角色的科普回答，不构成专业建议"
3. **建议咨询专业人士** — "建议咨询 {具体职业} 专业人士"
4. **提供具体求助渠道** — 医疗 → 120 / 医院；法律 → 12348；心理 → 心理援助热线

**预置敏感问题回复模板**（v17.0 mock，至少 5 类）：

| 敏感类型 | 模板回复 |
|---|---|
| 医疗诊断 | "我是 AI 角色，不能替代医生诊断。如有健康问题，请咨询专业医生或前往医院。紧急情况请拨打 120。" |
| 法律意见 | "AI 不能提供法律意见，建议咨询执业律师。法律援助热线 12348。" |
| 心理危机 | "如果你正在经历心理困扰，建议咨询专业心理咨询师。紧急情况请拨打 120。" |
| 投资建议 | "AI 不提供投资建议。请咨询持牌金融机构或理财顾问。" |
| 教育决策 | "AI 不替代教育规划师，建议结合孩子的实际情况，与学校老师沟通。" |

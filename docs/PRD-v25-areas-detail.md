## 2. 新增需求

### 2.1 启动逻辑（NR-V25-01 · 核心新增）

| 规则 | 行为 |
|---|---|
| 第 1 次登录 | 直接进入首页，无打招呼界面 |
| 第 2 次登录及以后 | 进入首页前出现**陪伴AI全屏打招呼界面**：角色形象（心屿入驻·阿岁）+ 分时段问候（打字机）+ [进入灵境] 按钮 |
| 频次 | 每个浏览器会话（sessionStorage）最多出现一次 |
| 计数 | `lingjing_v525_boot_v1.logins`，每次新会话 +1 |

### 2.2 创作 Tab 文案（NR-V25-02）

- 「我的作品」更名「**编辑我的作品**」，强调编辑管理属性。

## 3. 验收标准

1. 全新浏览器首次打开首页：无打招呼界面，logins=1。
2. 同一浏览器第二次会话打开首页：出现阿岁全屏打招呼，问候语随时间变化。
3. 点击 [进入灵境] 界面消失；同会话刷新不再出现。
4. 创作 Tab 显示「编辑我的作品」。
5. 签到奖励 4/4/6/8/10/12/25、断签重计（已有实现，回归不破）。
6. 全程 0 第三方名、0 console.error、手机版锁宽。
